# Claude Code 초급자 완벽 가이드

AI 기반 코딩 보조 도구 **Claude Code**를 처음부터 마스터하기 위한 한국어 가이드입니다.

## 문서 목록

| 문서 | 설명 | 대상 |
|------|------|------|
| [**GUIDE.md**](./docs/GUIDE.md) | 초급자 완벽 가이드 (시각 자료 포함) | 모든 사용자 |
| [**CHEATSHEET.md**](./docs/CHEATSHEET.md) | 빠른 참조 치트시트 | 빠른 참고용 |

## 포함 내용

- 설치 및 첫 실행 가이드
- 모든 슬래시 명령어 (`/help`, `/clear`, `/model` 등) 전체 정리
- 모든 키보드 단축키 (`Ctrl+C`, `Shift+Tab` 등) 전체 정리
- 권한 시스템 완벽 설명
- 프롬프트 입력 방법 및 팁
- MCP 서버 연결 가이드
- Hooks 자동화 설정
- 설정 파일 (CLAUDE.md, settings.json) 작성법
- IDE 통합 (VS Code, JetBrains)
- 실전 워크플로우 예시
- 초급자 팁 및 흔한 실수

## 시각 자료

이 가이드는 GitHub에서 렌더링되는 **Mermaid 다이어그램**을 활용하여 시각적으로 설명합니다:

- 아키텍처 다이어그램
- 워크플로우 순서도
- 시퀀스 다이어그램
- 마인드맵
- Git 그래프
- ASCII 아트 테이블

> GitHub에서 직접 보면 모든 다이어그램이 자동으로 렌더링됩니다.

## 빠른 시작

```bash
# 1. Claude Code 설치
curl -fsSL https://claude.ai/install.sh | bash

# 2. 프로젝트에서 실행
cd /your/project
claude

# 3. 프로젝트 초기화
/init
```
