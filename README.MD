# Ubermensch — 능동적 회상 학습 SPA

브라우저에서 바로 도는 학습 도구. **개념화 → 능동적 회상 → 문제 풀이 → 간격 반복** 사이클을 한 화면 안에서 돌립니다.

## 실행

```
index.html 더블클릭
```

서버, npm, 빌드 도구 없습니다. 모든 데이터는 브라우저 `localStorage`에 저장됩니다.

## 사용법

1. **덱(과목) 만들기** — 대시보드에서 `+ 새 덱` (예: 헌법, 영단어).
2. **노트 추가** — 개념을 *파인만식*으로 적습니다.
3. **본문에 마크업** — 외울 단어를 `{{단어}}` 또는 `**단어**` 로 감싸면
   - 자동으로 **빈칸(클로즈) 카드** 생성 대상이 되고,
   - 동시에 **회상 채점의 키워드**로 등록됩니다.
4. **Q/A 페어** 추가 — 객관식/단답형 문제집 효과.
5. **클로즈 카드 생성** 버튼으로 빈칸 카드 일괄 생성.
6. **오늘 복습** — 능동적 회상(안 보고 쓰기) + 퀴즈 풀이.
7. **Leitner 박스 (1→2→3→4→5)** — 정답이면 다음 박스, 오답이면 1번 박스.
   - 박스 간격: 1 / 3 / 7 / 14 / 30일.

## 데이터 백업

설정 페이지에서 **JSON 내보내기/가져오기**. 브라우저 캐시가 정리되면 데이터가 사라질 수 있으니 정기 백업을 권장합니다.
