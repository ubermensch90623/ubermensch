# Ubermensch - 에이전트 자기정교화 시스템

다수의 AI 에이전트가 서로 토론하고, 비평하고, 개선하여 스스로 작업을 정교화하는 시스템.

## 핵심 개념

```
태스크 → [설계자, 비평가, 구현자, 검토자] → 토론 → 합의 → 정교화 → 최종 결과
              ↑                                              |
              └──────────── 피드백 반영하여 재토론 ────────────┘
```

## 구조

```
ubermensch/
├── agents/          # 에이전트 정의
│   ├── base.py      # 기본 에이전트 (토론, 비평, 투표, 개선)
│   └── roles.py     # 역할 프리셋 (6가지)
├── core/            # 핵심 엔진
│   ├── debate.py    # 토론 엔진 (다수 에이전트 토론 → 합의)
│   └── refinement.py # 자기정교화 루프 (토론 → 평가 → 개선 반복)
├── tasks/           # 태스크 관리
│   └── watcher.py   # 태스크 감시 (큐 모니터링 → 자동 실행)
├── config/          # 설정
│   └── settings.py  # 시스템 설정
└── main.py          # 진입점
```

## 사용법

```bash
export ANTHROPIC_API_KEY="your-key"

# 단일 태스크 (토론 + 정교화)
python main.py run "API 서버의 인증 시스템을 설계하라"

# 토론만 (정교화 없이)
python main.py run "마이크로서비스 아키텍처 설계" --no-refine

# 전체 팀(6명)
python main.py run "데이터 파이프라인 설계" --full-team

# 태스크 큐에 추가
python main.py add "로깅 시스템 개선" --priority high

# 감시 모드 (태스크가 생기면 자동 실행)
python main.py watch

# 대화형 모드
python main.py interactive
```

## 에이전트 역할

| 역할 | 관점 |
|------|------|
| 설계자 | 전체 구조, 확장성, 모듈화 |
| 비평가 | 약점, 보안, 성능 문제 탐색 |
| 구현자 | 실용성, 코드 품질, 배포 가능성 |
| 검토자 | 종합 평가, 균형 잡힌 결론 |
| 창의자 | 새로운 접근법, 혁신적 해결책 |
| 사용자대변인 | 사용성, UX, 접근성 |

## 작동 흐름

1. **초기 제안**: 각 에이전트가 자기 관점에서 해결안 제시
2. **토론 라운드**: 상호 비평 → 피드백 반영 → 개선안 생성 (최대 5라운드)
3. **투표**: 합의 점수 계산 (0.8 이상이면 통과)
4. **정교화**: 품질 미달 시 재토론 (최대 3회 반복)
5. **결과**: 최종 합의된 결과물 출력 + 토론 로그 저장
