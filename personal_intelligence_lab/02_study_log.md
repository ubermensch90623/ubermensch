# 02_study_log — NCS / 경제학 학습 로그

> 공부 끝나자마자 위에 블록 1개 추가(append-on-top).
> 누적 오답 표는 영구 섹션. 같은 유형 틀릴 때마다 +1.

---

## 사용 규칙
1. 블록 1개 = 1 세션. 하루 여러 세션이면 블록 여러 개.
2. 누적 오답 표 카운트는 손으로 +1 (의식 행동).
3. 같은 유형 3회 누적 시 → 다음날 슬롯 1 단일 과제로 강제 배정.
4. AI에게 물어볼 질문은 "AI에게 물어볼 질문" 칸에 적어두고 `07_prompt_library.md` 4번/5번 프롬프트로 분석.

---

```
## YYYY-MM-DD HH:MM — <NCS or 경제학> 세션
- 푼 문제 수:
- 맞은 문제 수:
- 틀린 문제 수:
- 정답률:    %
- 틀린 유형 태그: #
- 왜 틀렸는가 (1줄):
- 다음에 같은 유형을 보면 어떻게 할 것인가 (1줄):
- 내일 복습할 문제 번호/개념:
- AI에게 물어볼 질문:
- 누적 오답 표 +1 완료? [ ]
```
