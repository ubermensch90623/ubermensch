# scripts/start_day — 아침 시작 절차 (러너북)

> 셸 스크립트가 아니라 수동 실행 절차다.
> 책상 앞에 앉자마자 위에서부터 따라간다. 5분.

---

## 1. 언제 실행하는가
- 아침 첫 책상 앞 / 25분 타이머 시작 직전.
- 늦은 오후 시작이라도 동일 절차.

## 2. 무엇을 입력하는가
- 어제 `01_today.md`의 "오늘의 한 줄 결론"
- 오늘의 가용 시간(분)
- 현재 에너지(1–5)
- 외부 일정/방해 요인

## 3. 실행 단계
- [ ] 폰을 다른 방에 둔다.
- [ ] `00_dashboard.md`를 연다.
  - [ ] 오늘의 목표 1개 채움
  - [ ] 제약조건 3개 채움
  - [ ] 출력물 1개 채움 (저녁에 보여줄 수 있는 형태)
  - [ ] 금지 입력 체크박스 4개 모두 체크
- [ ] `01_today.md`를 연다.
  - [ ] 에너지/가용 시간/제약 채움
  - [ ] 최소 목표 1줄
  - [ ] 슬롯 1 단일 과제 1줄 (어제 결론에서 자연스럽게 이어지는 것)
- [ ] (피곤한 날) `00_dashboard.md`/`01_today.md` 대신 `TODAY_ONLY.md`만 연다.
- [ ] (선택) AI에 `07_prompt_library.md` 7번 "하루 계획 생성" 프롬프트 사용.

## 4. 무엇이 출력되어야 하는가
- `00_dashboard.md` 모든 칸이 1–2줄로 채워진 상태.
- `01_today.md` 슬롯 1 단일 과제가 명사+동사로 적힌 상태 (예: "경제학 미시 5문제 풀이").

## 5. 실행 후 다음 행동
- 25분 타이머 시작 → 슬롯 1 단일 과제만 실행.
- 충동 발생 시 → `06_distraction_blocker.md` 복귀 문장 1번 읽고 즉시 복귀.
- 25분 끝 → 결과 한 줄 적기 → 슬롯 2 채울지 결정.

---

## 트러블슈팅
- 슬롯 1 단일 과제가 안 떠오름 → `04_thinking_upgrade.md`에서 카드 1장 골라 "이 사람이라면 오늘 무엇을 할까?"로 강제 변환.
- `00_dashboard.md` 채우는 데 5분 이상 걸림 → 그날은 `TODAY_ONLY.md`로 전환.
- 어제 결론이 비어 있음 → 누적 오답 표에서 카운트 최대 분야를 슬롯 1 과제로 자동 배정.
