# scripts/weekly_review — 일요일 주간 리뷰 절차 (러너북)

> 매주 일요일 저녁 15분.
> 절대 30분 넘기지 않는다. 길어지면 항목을 더 줄인다.

---

## 1. 언제 실행하는가
- 매주 일요일 저녁(고정 시각 권장: 21:00 ~ 21:15).
- 컨디션 안 좋으면 토요일 아침으로 당겨도 됨. 단, 한 주에 1번은 무조건.

## 2. 무엇을 입력하는가
- 지난 7일치 `01_today.md`의 "오늘의 한 줄 결론"
- 지난 7일치 `02_study_log.md`의 일일 블록
- 지난 7일치 `03_failure_log.md`의 블록
- 지난 7일치 `06_distraction_blocker.md`의 충동 카운터
- `05_automation_ideas.md`의 우선순위 A 후보

## 3. 실행 단계 (15분 타이머 시작)

### Phase A: 추출 (8분)
- [ ] `03_failure_log.md` 7일치 스캔 → 가장 반복된 실패 1줄 메모 (포스트잇/메모장)
- [ ] `02_study_log.md` 누적 오답 표·watch-list ✕ → 카운트 최대 분야 1개 메모
- [ ] `01_today.md` 마지막 7개 한 줄 결론 → 결과 좋았던 결론에 공통된 루틴 1개 메모
- [ ] `06_distraction_blocker.md` 충동 카운터 → 가장 자주 등장한 입력 1개 메모
- [ ] `05_automation_ideas.md` 우선순위 A → 1개 픽

### Phase B: 작성 (5분)
- [ ] `08_weekly_review.md`를 연다.
- [ ] `templates/weekly_review_template.md`를 복사해 가장 위에 붙여 넣는다.
- [ ] 위에서 메모한 5개를 그대로 옮긴다.
- [ ] **다음 주 실험 1개**: 변수 1개, 성공 기준 숫자 포함.
- [ ] **다음 주 최소 목표**: 매일 가능한 1줄.

### Phase C: 잇기 (2분)
- [ ] `01_today.md` 다음 주 첫째 날 "내일 첫 슬롯에서 할 일 1줄"에 다음 주 실험 1개를 옮겨 적기.
- [ ] `09_monthly_strategy.md`에 "이번 주 한 줄"만 추가 (월말에 모아서 사용).

### 선택: AI 분석
- [ ] `07_prompt_library.md` 8번 프롬프트 사용.
- [ ] 입력: Phase A에서 메모한 5개 + 7일치 블록 텍스트.
- [ ] 출력 그대로 `08_weekly_review.md` 새 주차 블록에 붙여넣기.

## 4. 무엇이 출력되어야 하는가
- `08_weekly_review.md`에 새 주차 블록 1개.
- 다음 주 실험 1개(변수 1개, 성공 기준 숫자).
- 다음 주 일요일 같은 시각에 다시 측정 가능한 형태.

## 5. 실행 후 다음 행동
- 화면 끄기.
- 다음 주 월요일 아침 → `scripts/start_day.md`로 복귀.

---

## 트러블슈팅
- 데이터가 너무 적음(빈 칸 많음) → 다음 주 실험은 "기록 자체"로. 변수: "매일 `01_today.md` 한 줄 결론을 빠뜨리지 않는다."
- 같은 실패 4주 연속 1위 → 구조 변경 안건. `09_monthly_strategy.md` "이번 달 가장 큰 병목"에 즉시 반영.
- 자동화 후보 모두 우선순위 C → 이번 주는 자동화 시도 X. 그 시간을 슬롯 1 단일 과제로.
