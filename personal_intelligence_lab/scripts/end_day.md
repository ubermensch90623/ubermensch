# scripts/end_day — 하루 마감 절차 (러너북)

> 마지막 25분 슬롯이 끝난 직후 실행.
> 5–7분. 끝나면 화면을 끈다.

---

## 1. 언제 실행하는가
- 마지막 25분 슬롯 종료 후 30초 안.
- 졸리거나 피곤해도 최소 항목(아래 ★)은 실행.

## 2. 무엇을 입력하는가
- 오늘 푼 문제 수 / 맞은 수 / 틀린 유형
- 실패 1건(있을 때)
- 자동화 후보 0–1개 (귀찮은 일 발견했을 때)
- 슬롯별 결과 한 줄

## 3. 실행 단계

### ★ 최소 (피곤한 날도 실행)
- [ ] `01_today.md` "오늘의 한 줄 결론" 채움
- [ ] `01_today.md` "내일 첫 슬롯에서 할 일 1줄" 채움 (← 내일 아침 시작점)

### 표준
- [ ] `02_study_log.md`
  - [ ] 일일 블록 1개 추가 (`templates/study_template.md` 복붙)
  - [ ] 누적 오답 표 +1
  - [ ] watch-list ✕ 추가(해당 시)
- [ ] `03_failure_log.md` (실패 있을 때만)
  - [ ] 블록 1개 추가 (`templates/failure_template.md` 복붙)
  - [ ] 변수 1개만 적었는지 재확인
- [ ] `05_automation_ideas.md` (반복 작업 발견 시만)
  - [ ] 1줄 등록 영역에 한 줄
- [ ] `00_dashboard.md` "오늘 끝났을 때 한 줄 결론" 채움

### 충동/반추가 있었던 날
- [ ] `06_distraction_blocker.md` 충동 카운터 표에 1행 추가
- [ ] 다음 날 차단 실험 변수 1개 결정

## 4. 무엇이 출력되어야 하는가
- `01_today.md`에 한 줄 결론 + 내일 첫 슬롯 할 일이 채워져 있어야 함.
- `02_study_log.md`에 오늘 블록이 가장 위에 있어야 함.
- 누적 오답 표가 +1 된 상태.

## 5. 실행 후 다음 행동
- 화면 끄기. 이후 정보 입력 금지(뉴스/유튜브/검색).
- AI에 추가 분석 원하면 → 끄기 전에 `07_prompt_library.md` 4번/5번 프롬프트만 사용.

---

## 트러블슈팅
- 너무 피곤함 → ★ 최소 2줄만 채우고 끝. 다른 항목은 내일 아침 보충 X (오늘 데이터로 확정).
- 실패가 너무 많음 → 1건만 골라 적는다. 나머지는 내일.
- 다음 날 첫 슬롯 할 일이 안 떠오름 → "어제 슬롯 1 단일 과제 + 누적 오답 표 최대 분야"로 임시 배정.
