# personal_intelligence_lab

> **이 시스템은 나를 위로하기 위한 것이 아니다. 내 사고를 출력으로 바꾸기 위한 개인 연구소다.**

---

## 0. 선언

```
나는 천재가 아니어도 된다.
대신 천재들의 사고 알고리즘을 복사해서 내 하루에 실행한다.
나는 재능으로 이기는 사람이 아니라,
고성능 사고방식을 복제·실행·누적해서 이기는 사람이 된다.
```

---

## 1. 이 시스템의 목적

- 매일 25분 안에 출력물 1개를 만든다.
- NCS·경제학 오답을 데이터로 누적한다.
- 실패를 자책 대신 NASA식 변수 1개 변경으로 바꾼다.
- 반추·유튜브·뉴스·검색 루프를 차단 규칙과 복귀 문장으로 끊는다.
- AI를 자유 대화가 아니라 `07_prompt_library.md`의 프롬프트로만 쓴다.

---

## 2. 매일 사용 순서 (5단계)

1. 아침: `00_dashboard.md`를 연다 → 목표 1·제약 3·출력물 1·금지 입력 확인
2. 책상 앞: `01_today.md`를 연다 → 25분 슬롯 첫 칸의 단일 과제를 시작
3. 25분 종료: 결과 한 줄을 `01_today.md`에 적는다
4. 공부 후: `02_study_log.md`에 일일 블록 추가 + 누적 오답 표 +1
5. 실패 발생 시: `03_failure_log.md`에 블록 1개 추가, 변수 1개만 적는다

부수 흐름:
- 잡생각/충동 발생 → `06_distraction_blocker.md` 복귀 문장 읽고 25분 슬롯으로 복귀
- 귀찮은 반복 발견 → `05_automation_ideas.md`에 한 줄 던져두고 일요일에 평가
- 사고가 막힘 → `04_thinking_upgrade.md`에서 질문을 한 단계 위로 올린다

---

## 3. 25분 최소 실행법 (피곤한 날)

`TODAY_ONLY.md` 한 파일만 연다. 7섹션, 5분 안에 작성. 다른 파일은 건너뛴다.

---

## 4. 공부 실패 시 복구법

1. 자책 멈춘다. 30초 안에 `03_failure_log.md`를 연다.
2. 블록 1개를 위에 추가한다 (가설 / 결과 / 원인 후보 / 바꿀 변수 1개).
3. 변수 1개만 바꾼 채 25분 타이머를 다시 켠다.
4. 같은 실패 3회 누적 시 `08_weekly_review.md`로 옮겨 구조 변경 검토.

---

## 5. 유튜브·검색·뉴스 복귀법

`06_distraction_blocker.md`의 복귀 문장:

> **"지금 찾는 것은 정보인가, 안정감인가?**
> **행동을 낳지 않으면 반추로 폐기한다."**

규칙:
- 공부 전 유튜브 금지
- 뉴스 1일 1회 10분
- 정치/연예 클릭 금지
- 검색하고 싶으면 먼저 문제 1개 풀기
- 충동 시 → `07_prompt_library.md` 프롬프트 6번을 AI에 붙여넣기

---

## 6. 주간 리뷰 방법 (일요일 저녁 15분)

`scripts/weekly_review.md`를 따라간다. 출력은 `08_weekly_review.md`에 새 주차 블록으로 누적.

요지:
1. `03_failure_log.md` 7일치 → 가장 반복된 실패 1줄
2. `02_study_log.md` 누적 오답 표 → 최대 카운트 태그
3. `01_today.md` 마지막 7개 한 줄 결론 → 효과 있었던 루틴
4. `05_automation_ideas.md` → 다음 주 자동화 1개 픽
5. 다음 주 실험 1개 (변수 1개만)

월 1회: `09_monthly_strategy.md`에 월간 블록 추가.

---

## 7. AI 협업법 (Claude / ChatGPT / Gemini)

규칙:
- 자유 대화 금지. `07_prompt_library.md`의 8개 프롬프트 중 하나로만 시작.
- 입력은 `02_study_log.md` / `03_failure_log.md` / `05_automation_ideas.md` 블록을 그대로 복붙.
- 출력은 다음 행동 1개로 끝나야 한다. 끝나지 않으면 프롬프트가 잘못됨 — 수정.

8개 프롬프트:
1. 머스크식 문제 분해
2. NASA식 실패 분석
3. 엔비디아식 자동화 탐색
4. NCS 오답 분석
5. 경제학 오답 분석
6. 유튜브 중독 복귀
7. 하루 계획 생성
8. 주간 리뷰

## 8. 파일 지도

| 파일 | 언제 연다 | 무엇을 한다 |
| --- | --- | --- |
| `00_dashboard.md` | 아침 첫 화면 | 오늘의 선언/목표/제약/출력물/금지 입력 |
| `01_today.md` | 25분 시작 직전 | 25분 루틴 체크박스 채우고 단일 과제 |
| `02_study_log.md` | 공부 직후 | 푼/맞/틀 + 누적 오답 표 +1 |
| `03_failure_log.md` | 실패 발생 직후 | NASA식 블록 1개 |
| `04_thinking_upgrade.md` | 사고 막힐 때 | 낮은 질문 → 높은 질문 → 실행 질문 |
| `05_automation_ideas.md` | 귀찮은 일 발견 | 한 줄 던지기 (평가는 일요일) |
| `06_distraction_blocker.md` | 충동 발생 시 | 복귀 문장 + 차단 규칙 확인 |
| `07_prompt_library.md` | AI 쓰기 직전 | 8개 프롬프트 복사 |
| `08_weekly_review.md` | 일요일 저녁 | 주차 블록 추가 |
| `09_monthly_strategy.md` | 월말 | 월간 블록 추가 |
| `TODAY_ONLY.md` | 피곤한 날 | 1페이지로 하루 끝 |
| `templates/` | 새 블록 추가 시 | 빈칸 양식 복붙 소스 |
| `archive/` | 월말 | 30일 이전 블록 이동 |
| `scripts/start_day.md` | 아침 첫 절차 | 어떤 파일을 어떤 순서로 |
| `scripts/end_day.md` | 마지막 25분 후 | 마무리 절차 |
| `scripts/weekly_review.md` | 일요일 저녁 | 리뷰 절차 |
