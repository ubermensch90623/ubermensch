# weekly_review_template

> 일요일 저녁. `scripts/weekly_review.md` 절차를 먼저 따라간 뒤,
> 이 템플릿을 복사해 `08_weekly_review.md` 본문 가장 위에 붙여 넣는다.

```markdown
## YYYY-Www (YYYY-MM-DD ~ YYYY-MM-DD)
- 이번 주 총 공부량(문제 수 / 세션 수):
- 가장 많이 틀린 유형:
- 가장 자주 무너진 시간대:
- 가장 많이 빠진 입력 (유튜브/검색/뉴스/커뮤니티 중):
- 효과 있었던 루틴 1개:
- 제거할 루틴 1개:
- 가장 반복된 실패 1줄:
- 다음 주 실험 1개:
  - 변수 1개:
  - 성공 기준(숫자):
  - 측정 시점:
- 다음 주 최소 목표(매일 가능한 1줄):
- 이번 주 자동화 1개 결과:
  - 상태: 시도중 / 완료 / 폐기
  - 다음 행동:
- 한 줄 총평(자기 위로 X, 데이터로):
```

추출 소스 매핑:
- "가장 반복된 실패" ← `03_failure_log.md` 반복 실패 카운터
- "가장 많이 틀린 유형" ← `02_study_log.md` 누적 오답 표 + watch-list
- "효과 있었던 루틴" ← `01_today.md` 마지막 7개 한 줄 결론
- "다음 주 실험 1개 후보" ← `05_automation_ideas.md` 우선순위 A
- "가장 많이 빠진 입력" ← `06_distraction_blocker.md` 충동 카운터

선택적: `07_prompt_library.md` 8번 프롬프트에 위 4개 입력을 붙여넣고 AI 출력 그대로 옮겨도 됨.
