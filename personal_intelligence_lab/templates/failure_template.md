# failure_template

> 실패 발생 즉시 복사해서 `03_failure_log.md`의 본문 가장 위에 붙여넣기.
> 변수는 1개만 바꾼다(절대 2개 이상 X).

```markdown
## YYYY-MM-DD HH:MM — <한 줄 실패 제목>
- 오늘의 실패:
- 원래 가설(이렇게 하면 될 줄 알았다):
- 실제 결과:
- 관찰된 데이터(시간, 횟수, 패턴):
- 실패 원인 후보 (3개):
  1)
  2)
  3)
- 다음 실험에서 바꿀 변수 1개:
- 재발 방지 체크리스트:
  - [ ]
  - [ ]
- 반복 여부: 처음 / 2회 / 3회 이상(⚠️)
```
