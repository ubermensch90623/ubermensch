# automation_template

> 귀찮은 반복 작업 발견 즉시 1줄 등록.
> 정식 블록은 일요일 리뷰 때 채운다.

## 즉시 1줄 등록 형식 (`05_automation_ideas.md` 상단 1줄 영역에)

```
- YYYY-MM-DD — <반복 작업 한 줄>
```

## 정식 블록 (일요일에 복사해서 `05_automation_ideas.md` 본문 가장 위에)

```markdown
## YYYY-MM-DD — <반복 작업 제목>
- 반복 작업(무엇을 반복하는가):
- 왜 귀찮은가(시간/감정/맥락 손실):
- 1회당 소요 시간(분):
- 주당 발생 횟수:
- 자동화 가능 여부 (Y/N/부분):
- AI에게 맡길 수 있는 부분(프롬프트 초안 1줄):
- 필요한 도구(GPT/Claude/Gemini/스크립트/단축키):
- 예상 절약 시간(분/주):
- 우선순위 (A/B/C):
  - A: 매일 반복 + 1회 10분↑
  - B: 주 2–3회
  - C: 가끔이지만 스트레스 큰 일
- 다음 행동(이번 주 1개 행동):
- 성공 기준(숫자):
- 상태: 후보 / 시도중 / 완료 / 폐기
```

다음 행동:
- AI 분해 원하면 → `07_prompt_library.md` 3번 프롬프트에 위 블록 입력.
- 한 주에 자동화 시도는 1개만(엔비디아식 병목 집중).
