# 03_failure_log — NASA식 실패 기록

> 실패 1건 = 블록 1개. 변수는 1개만 바꾼다.
> 자책 금지. 데이터로 본다.
> 가장 위에 새 블록 추가(append-on-top).

---

## 사용 규칙
1. 실패 발생 후 30초 안에 이 파일을 연다.
2. 블록 1개를 가장 위에 추가한다.
3. "다음 실험에서 바꿀 변수"는 **반드시 1개**. 2개 이상 적으면 데이터가 무효.
4. 같은 실패 3회 이상 누적 시 옆에 ⚠️ 표시 → 일요일 `08_weekly_review.md`에 구조 변경 안건으로 올린다.

---

## 블록 템플릿 (복사해서 위에 붙여넣기)

```
## YYYY-MM-DD HH:MM — <한 줄 실패 제목>
- 오늘의 실패:
- 원래 가설(이렇게 하면 될 줄 알았다):
- 실제 결과:
- 관찰된 데이터(시간, 횟수, 패턴):
- 실패 원인 후보 (3개):
  1)
  2)
  3)
- 다음 실험에서 바꿀 변수 1개:
- 재발 방지 체크리스트:
  - [ ]
  - [ ]
- 반복 여부: 처음 / 2회 / 3회 이상(⚠️)
```

## (여기부터 실패 블록 누적 — 가장 위에 새 블록 추가)

## 0000-00-00 00:00 — [시드 예시] 공부하려다 유튜브 40분 시청
- 오늘의 실패: 공부 시작 직전 유튜브 홈을 열었고 40분간 시청.
- 원래 가설: 잠깐만 보면 괜찮을 줄 알았다.
- 실제 결과: 공부 시작이 40분 지연, 피로 누적, 슬롯 1 미실행.
- 관찰된 데이터: 유튜브 홈 화면 진입 → 첫 영상 클릭까지 평균 12초, 총 클릭 수 6회.
- 실패 원인 후보 (3개):
  1) 책상 앞에서 폰을 손에 들고 있었음
  2) 슬롯 1 단일 과제가 아직 정해지지 않았음 (셋업 미완)
  3) 유튜브 앱 위치가 홈 첫 화면
- 다음 실험에서 바꿀 변수 1개: 공부 전 유튜브 앱을 열지 않는다. 필요한 영상은 브라우저에서 직접 URL로 접근한다.
- 재발 방지 체크리스트:
  - [ ] 책상 앞에 앉기 전 폰을 다른 방에 둔다
  - [ ] 슬롯 1 단일 과제는 전날 밤 `01_today.md`에 미리 적어둔다
- 반복 여부: 처음

> 이 시드 블록은 첫 사용 마찰 제거용. 자기 첫 실패 블록을 추가하면 시드는 그대로 둬도, 지워도 무방.
