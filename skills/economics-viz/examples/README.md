# economics-viz 시연 예시

이 폴더는 `economics-viz` 스킬의 **실제 렌더링 결과**를 보관합니다. SKILL.md 워크플로가 의도대로 동작하는지 한눈에 확인할 수 있는 참고용입니다.

## 1. `demand_increase_equilibrium.svg` / `.png`

**질문**: "수요 증가가 균형에 미치는 영향을 보여줘"

**가정**: 선형 수요·공급
- 원래 수요: $P = 10 - 0.8Q$
- 증가 후 수요: $P = 12 - 0.8Q$ (평행이동)
- 공급: $P = 2 + 0.6Q$

**균형점**

| | Q | P |
|---|---|---|
| E (원래) | 5.71 | 5.43 |
| E′ (수요 증가 후) | 7.14 | 6.29 |
| Δ | +1.43 | +0.86 |

**환경**: `Noto Sans CJK JP` 폴백으로 한글 라벨 렌더링 (한국어 전용 폰트 없는 환경 대응).

재생성하려면 SKILL.md의 보일러플레이트를 그대로 따르면 됩니다.
