# 공유 메모리 (Shared Memory)

이 파일은 모든 AI 에이전트가 공유하는 프로젝트 컨텍스트입니다.
각 에이전트는 작업 전 이 파일을 읽고, 작업 후 업데이트합니다.

## 프로젝트 개요

- **프로젝트명**: ubermensch
- **설명**: 멀티 AI 에이전트 협업 워크스페이스
- **생성일**: 2026-02-28

## 현재 상태

- 초기 세팅 완료
- 공유 워크스페이스(`clawd/`) 구조 생성됨

## 핵심 결정사항

| 날짜 | 결정 | 담당 에이전트 |
|------|------|---------------|
| 2026-02-28 | 공유 워크스페이스 구조 설계 | Claude Code |

## 주의사항

- 이 파일을 수정할 때는 충돌을 방지하기 위해 섹션 단위로 추가합니다.
- 한국어 인코딩은 UTF-8을 사용합니다.
- 각 에이전트는 자신의 작업 내역을 `logs/` 디렉토리에 기록합니다.
