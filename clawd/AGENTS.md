## 협업 프로토콜

### 작업 시작 시
1. `clawd/MEMORY.md`를 읽어 현재 프로젝트 상태를 파악한다.
2. 이 파일에서 자신의 상태를 "활성"으로 업데이트한다.
3. 자신의 feature 브랜치에서 작업을 시작한다.

### 작업 종료 시
1. `clawd/MEMORY.md`의 "현재 상태" 섹션을 업데이트한다.
2. `clawd/logs/YYYY-MM-DD.md`에 작업 내역을 기록한다.
3. 변경사항을 커밋하고 브랜치에 push한다.

### 충돌 방지 규칙
- 같은 파일을 동시에 수정하지 않는다.
- 공유 파일(`MEMORY.md` 등) 수정 시 섹션 단위로 추가한다.
- 확실하지 않으면 사용자에게 확인한다.
- 인코딩은 반드시 UTF-8을 사용한다.
