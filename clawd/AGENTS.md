## 협업 규칙

1. 작업 시작 전 `MEMORY.md`를 읽어 현재 프로젝트 상태를 파악합니다.
2. 작업 완료 후 `MEMORY.md`를 업데이트합니다.
3. 모든 작업은 `logs/YYYY-MM-DD.md`에 기록합니다.
4. 다른 에이전트의 작업 영역과 충돌하지 않도록 주의합니다.
5. 파일 인코딩은 반드시 UTF-8을 사용합니다.
