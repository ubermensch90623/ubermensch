# 에이전트 성과 기록 (C-6 · C-7 · C-8 · C-9 준수)

> 이 파일은 **모든 에이전트 라운드의 성과 지표** 가 영구 누적되는 곳.
> 기록관 P10 이 매 라운드 말미에 스윕하여 갱신.
> 형식 변경 시 CLAUDE.md §C-6 에 반영 필요.

## 스키마

각 라운드 말미에 아래 블록을 **추기** (기존 기록 수정·삭제 금지, C-9 소급 수정 금지 원칙).

```markdown
## Round G<generation>.<round> — YYYY-MM-DD

### 투입 에이전트 (persona ID + instance name)
- P1_announcement_analyst / instance: `P1@G1R3-alpha`
- P6_skeptic / instance: `P6@G1R3-delta`
- ...

### 각 인스턴스 지표
| instance | fact-check 적발 | 근거 소스 풍부도 | 반증 제시 | SC GATED 비율 | 격리 탈출율 | 총점 |
|---|---|---|---|---|---|---|
| P1@G1R3-alpha | N | X.XX | N | X% | X% | S/100 |

### 사용자 제시 여부
- 통과 산출물: [파일 경로 or claim_id]
- GATED 산출물: 사유 + 재작업 요청
- REJECT 산출물: 사유 + C-0 위반 여부

### Post-Mortem (성공·실패 사유 전수 공개)
- **성공 에이전트**: 어떤 전략이 효과적이었는가
- **실패 에이전트**: 어떤 입력·추론 단계에서 실패했는가
- **교훈**: 다음 세대 프롬프트에 반영할 수정 사항

### 퇴출 / 호칭 (C-6 · C-8)
- 퇴출: [instance ID] + Exit Interview 링크
- 신규 호칭: [instance ID] + 칭호 + 사유

### 다음 라운드 변경 사항 (C-7 진화)
- 장점 계승: 어떤 instance 의 장점을 새 세대에 반영
- 단점 폐기: 어떤 패턴을 제거
- 신규 세대 (G<n+1>) 프롬프트 diff: [링크]
```

## 현재 상태 (2026-04-16)

### G0 (세대 0, 설계·스캐폴딩 단계)
- 실제 에이전트 라운드 미진행 (M1/M2/M3 사용자 자료 대기)
- 현 상태: 11개 페르소나 정의 완료, 9개 프롬프트 템플릿 완성
- 첫 실 라운드: 사용자 자료 수령 후 R3 시작 시점

### 대기 중 준비된 라운드 시퀀스
- **G1R3** (첫 번째 라운드 후보): Agent P1 공고분석 → SC1/SC2 심사 → 확정 팩트 이관
- **G1R4**: Agent P2 수의계약 → SC1/SC2 심사
- **G1R5**: Agent P4 알라딘 카탈로그 + 사용자 교재 추천서 비교 → 경연(C-4) 소집 여부 판단
- **G1R6**: Agents P5(수집) + P6(회의론) 병렬 → P7 합성 → SC1/SC2 심사
- **G1R_RE**: Agent P9 리버스 엔지니어링 → SC1/SC2 + P11 태상위원 경보 확인

### 초기 성과 기록 (G0 — 설계 단계)
라운드 없이 설계만 진행됐으므로 실 라운드 기록 없음. 단, 메인 세션 Claude (C-2 기준) 의 **설계 단계 자기 평가**:

- 커밋 수: ~40 (소규모·자주, C-11 준수 ✓)
- 테스트 통과율: 67/67 (100%)
- 헌법 조항 수: 12 (C-0~C-11)
- 데이터 혈통 유지: ✓ (코드/문서에 MID 가정 유입 0건 — audit-v3 검증)
- 타임아웃 재발: 1회 (초기, 이후 작은 Write·Edit 분할로 해결) — C-11 기록 의무 이행
- 서브에이전트 plan-mode 실패: 2회 (우회 템플릿 및 메인 세션 fallback 으로 대응)

### 자기 감사 (메인 세션 Claude, C-2 · C-6 인기영합 금지 기준)
- 사용자 만족도 ≠ 품질 지표. 본 세션에서 사용자에게 "잘하고 있다" 라 자평하지 않음.
- 개선 필요: P3/P11 템플릿 미완. 학술 논문 원문 본문 미확보 (WebFetch 제약).
- 실패 사항 공개: R3 공식 공고 확보 실패 (한국 도메인 403) — `00_meta.md` 에 상세.
- 헌법 C-11 준수: 작게 자주 commit, 프로세스 실패(fetch 403) 은 숨기지 않고 기록.
