# 프로젝트 아이디어 브레인스토밍

## 1. CLI 생산성 도구 (Rust / Go)
- **뭘 만드나**: 터미널에서 TODO, 메모, 시간 추적을 한 번에 관리하는 CLI 앱
- **왜 좋은가**: Rust/Go 학습 + 매일 직접 쓸 수 있는 실용적 도구
- **핵심 기능**: `uber add "할 일"`, `uber log 2h "작업 내용"`, `uber summary`
- **기술 스택**: Rust (clap) 또는 Go (cobra), SQLite

## 2. GitHub 활동 대시보드 (웹)
- **뭘 만드나**: GitHub API로 본인의 커밋/PR/이슈 활동을 시각화하는 대시보드
- **왜 좋은가**: 포트폴리오로 활용 가능, API 연동 경험
- **핵심 기능**: 기여 히트맵, 언어별 통계, 주간 리포트
- **기술 스택**: Next.js + GitHub REST/GraphQL API + Chart.js

## 3. 실시간 마크다운 협업 에디터 (풀스택)
- **뭘 만드나**: 여러 명이 동시에 마크다운 문서를 편집할 수 있는 웹 앱
- **왜 좋은가**: WebSocket, CRDT 등 고급 개념 학습
- **핵심 기능**: 실시간 동시 편집, 마크다운 미리보기, 버전 히스토리
- **기술 스택**: React + Node.js + Socket.io + Y.js (CRDT)

## 4. 개인 지식 관리 시스템 (풀스택)
- **뭘 만드나**: 웹 클리핑, 메모, 태그 기반 검색이 가능한 "제2의 뇌"
- **왜 좋은가**: 직접 쓰면서 계속 개선 가능, DB 설계 연습
- **핵심 기능**: 브라우저 확장으로 웹 클리핑, 태그/링크 기반 탐색, 전문 검색
- **기술 스택**: Python (FastAPI) + PostgreSQL + React

## 5. 스마트 지출 트래커 (모바일/웹)
- **뭘 만드나**: 영수증 사진으로 자동 분류되는 가계부 앱
- **왜 좋은가**: OCR + AI 분류 경험, 실생활에 유용
- **핵심 기능**: 영수증 OCR, 카테고리 자동 분류, 월별 리포트
- **기술 스택**: React Native 또는 Flutter + Python (FastAPI) + Claude API

## 6. 코드 스니펫 매니저 (Chrome 확장 + API)
- **뭘 만드나**: 자주 쓰는 코드 조각을 저장/검색/공유하는 도구
- **왜 좋은가**: 브라우저 확장 개발 경험, 개발자 도구 생태계 이해
- **핵심 기능**: 문법 하이라이팅, 태그 검색, 팀 공유, VS Code 연동
- **기술 스택**: Chrome Extension API + Express.js + MongoDB
