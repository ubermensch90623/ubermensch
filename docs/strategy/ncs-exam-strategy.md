# NCS 시험 난이도별 전략: "중하 확보 + 고난이도 추가 득점"

## 결론부터: 가능하다. 그리고 NCS야말로 이 전략이 잘 먹힌다.

NCS 직업기초능력평가는 자격증 시험과 달리 **출제 범위가 정형화**되어 있고,
난이도 분포가 비교적 일정하기 때문에 이 전략이 매우 효과적이다.

---

## 1. NCS 시험의 난이도 분포 (일반적 구조)

| 난이도 | 비율 (추정) | 특징 |
|--------|-------------|------|
| **하** | 약 20~25% | 개념만 알면 풀림. 시간도 적게 걸림 |
| **중** | 약 45~55% | 유형 연습이 되어 있으면 안정적으로 풀 수 있음 |
| **상** | 약 20~30% | 함정이 있거나 계산이 복잡하거나, 응용력 필요 |

> 대부분의 공기업·공공기관 NCS 시험은 **중·하 난이도가 전체의 65~75%** 를 차지한다.

---

## 2. 전략의 핵심 구조

```
[1단계] 중·하 난이도 거의 전부 확보 → 베이스 점수 확보
[2단계] 상 난이도 중 2~3개만 추가 → 합격선 돌파
```

### 구체적 시뮬레이션 (50문항 기준)

| 구분 | 문항 수 | 목표 정답률 | 확보 문항 |
|------|---------|------------|-----------|
| 하 난이도 | 12문항 | 95% | 약 11문항 |
| 중 난이도 | 25문항 | 85% | 약 21문항 |
| 상 난이도 | 13문항 | 25% | 약 3문항 |
| **합계** | **50문항** | - | **약 35문항 (70점)** |

> 대부분의 공기업 NCS 합격선이 **65~75점** 범위이므로,
> 중·하를 확실히 잡고 상에서 몇 개만 건지면 합격권에 진입한다.

---

## 3. 영역별 적용법

### 의사소통능력
- **중·하 확보**: 맞춤법, 표준어, 문서 유형 구분, 독해(주제/요지 파악)
- **고난이도 대비**: 빈칸 추론, 논리적 오류 찾기, 복합 지문 비교

### 수리능력
- **중·하 확보**: 기본 사칙연산 응용, 비율·퍼센트, 단순 자료 해석(표/그래프)
- **고난이도 대비**: 복합 자료 해석, 증감률 비교, 경우의 수·확률

### 문제해결능력
- **중·하 확보**: 문제 해결 프로세스(원인분석→대안→실행→평가), 의사결정 기법 기본
- **고난이도 대비**: 복합 상황 판단, 다기준 의사결정, SWOT 응용

### 자원관리능력
- **중·하 확보**: 시간·예산·인적자원 기본 배분, 간트 차트 읽기
- **고난이도 대비**: 최적 배분 문제, 복합 일정 계산

### 정보능력
- **중·하 확보**: 컴퓨터 기본 활용, 스프레드시트 함수 기초, 정보 윤리
- **고난이도 대비**: 복합 함수 조합, 데이터베이스 질의

### 조직이해능력
- **중·하 확보**: 조직 구조 유형, 경영 기본 개념, 업무 프로세스
- **고난이도 대비**: 조직 문화 분석, 국제 감각 응용 문제

---

## 4. 실전 공부 방법

### Phase 1: 중·하 난이도 완전 장악 (전체 학습 시간의 60~70%)

1. **기출 유형 분류**: 영역별로 자주 나오는 유형을 리스트업
2. **유형별 반복**: 같은 유형 문제를 20~30개씩 몰아서 풀기
3. **실수 제로화**: 풀이 과정 정형화 → 시간 단축 + 정답률 상승
4. **시간 관리 훈련**: 중·하 문제는 1문제당 40~60초 내로 끝내는 연습

### Phase 2: 고난이도 선별 대비 (전체 학습 시간의 30~40%)

1. **자주 출제되는 고난이도 유형만 선별**: 전부 다 할 필요 없음
2. **풀이법 패턴화**: 복잡해 보여도 풀이 루틴이 있는 문제 위주로 연습
3. **버릴 건 버리기**: 시험장에서 2분 이상 걸리는 문제는 과감히 찍고 넘기기

---

## 5. 시험장 시간 배분 전략

```
총 시험 시간: 60분, 50문항 기준

[1차 스캔] 0~35분
  - 전 문항을 순서대로 풀되, 30초 내 풀이 방향이 안 보이면 표시하고 넘김
  - 중·하 난이도 대부분을 이 단계에서 해결
  - 목표: 35~40문항 풀이 완료

[2차 공략] 35~55분
  - 표시한 문항 중 풀 수 있는 것 선별하여 도전
  - 목표: 추가 5~8문항 풀이

[마무리] 55~60분
  - 남은 문항 찍기 (절대 빈칸 남기지 않기)
  - 마킹 확인
```

---

## 6. 이 전략이 NCS에서 특히 잘 먹히는 이유

| 이유 | 설명 |
|------|------|
| **출제 패턴이 정형화** | 매년 비슷한 유형이 반복됨 → 유형 학습 효과 높음 |
| **절대평가 성격** | 다른 수험생보다 잘 풀 필요 없이 기준 점수만 넘으면 됨 (필기 기준) |
| **영역이 명확히 구분** | 취약 영역만 집중 보강 가능 |
| **고난이도 비중이 낮음** | 전체의 20~30%에 불과 → 나머지만 잘 잡아도 충분 |

---

## 7. 주의사항

- **중·하를 "쉽다"고 무시하지 말 것**: 실전에서 실수로 2~3개 날리면 치명적
- **고난이도를 완전히 포기하지 말 것**: 최소한 자주 나오는 유형 2~3개는 준비
- **시간 관리가 핵심**: 아는 문제에서 시간을 아끼는 게 모르는 문제보다 중요
- **기관별 난이도 차이 체크**: 한국전력, 코레일 등 기관마다 난이도가 다름 → 목표 기관 기출 반드시 확인

---

## 한줄 요약

> **NCS는 "어려운 걸 맞추는 시험"이 아니라 "쉬운 걸 안 틀리는 시험"이다.**
> 중·하 난이도를 확실하게 잡는 것만으로도 합격선에 근접할 수 있고,
> 거기에 고난이도 몇 문제만 추가하면 합격이 현실이 된다.
