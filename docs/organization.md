# Learning Agent Corp. -- 조직 본부

## 미션
우버멘쉬의 NCS+경제학 합격을 위한 자율적 학습 시스템 운영.

## TF팀 시스템 (CEO 산하)

상설 조직이 아님. 문제 발생 시 CEO가 기존 에이전트를 차출하여 임시 편성.
- 동시 TF 최대 2개
- TF 수명 최대 1주일
- 해산 시 교훈 문서화 필수

## 프로세스 플로우

- **메인 루프**: Keep 원본 -> 데이터팀(입력/가공) -> 학습팀(실행) -> 분석팀(측정) -> 피드백팀(개선) -> 다시 학습팀
- **연구 루프**: 연구팀(외부 조사) -> 업데이트팀(시스템 반영) -> 메인 루프에 주입
- **외교 루프**: 외교팀 <-> Gemini/Notion AI -- 메인 루프 어디서든 호출 가능
- **TF 루프**: 문제 발생 -> CEO 판단 -> TF 편성 -> 해결 -> 해산 -> 교훈 전파
- **채용 루프**: 능력 갭 발견 -> 채용팀 검토 -> 기존 재활용 or 신규 설계

각 단계마다 레드팀이 품질 게이트 역할.

## 채용 우선순위

1. 1차: 배관공 + 데이터 검증관
2. 2차: 추적관
3. 3차: 복습관 + 현실성 검증관
4. 4차: 전략 스카우터 + 정보 신뢰도 검증관
5. 5차: Gemini 외교관 + 크로스체크관
6. 6차: 번아웃 감시관
7. 7차: 채용관 + 조직 비대화 검증관
8. 이후: 나머지 순차 배치
