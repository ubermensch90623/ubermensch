## 소스 계층 (Hierarchy)
1. **1차 (Primary)**: 사용자 구매 기출 이북 (알라딘), 공식 채용공고, 나라장터 수의계약 공개 자료, 학술 논문
2. **2차 (Secondary)**: 공개 후기 (공준모 스니펫, 블로그, 유튜브 자막)
3. **3차 (Derived)**: 리버스 엔지니어링 생성 예상 문항 (근거 체인 필수)
4. **비소스**: 내 학습 데이터 상상, 출처 없는 일반론 → 즉시 기각
