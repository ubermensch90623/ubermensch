## 0. 박사팀 회의 요약 (회의론자 교차 검증 후)

### 합의된 원칙
1. **1차 소스 우선**: 기출 (사용자 실제 응시한 회차와 가까운 과년도) > 기본서 > 예상문제집
2. **유형별 대비 필수**: 서민금융진흥원이 어느 채용대행사와 계약했는지 미확인이므로 **모듈형·PSAT형·피듈형 전부 대비**
3. **NCS 3영역 한정 (의사소통·수리·문제해결)**: 저신뢰 스니펫이지만 복수 검색 교차확인됨 (C-0 MID → 구매 우선순위 조정에만 참고). 단, 최종 확정은 공고 PDF 검증 후.
4. **서민금융 법령**: 국가법령정보센터 무료 조문 + 나무위키 해설 → **별도 유료 교재 불필요** (무료 자료로 충분)
5. **3 트랙 모두 기본서 1권씩**: 사용자가 어느 트랙 응시했는지 확정 후 1권 제외 가능

### 회의론자 이의 (기각되지 않은 것)
- "NCS 3영역만 출제" 는 MID 신뢰도 → 만에 하나 10영역 전부일 경우 수리·의사소통·문제해결만 집중하면 30~40% 구멍. **통합 기본서** 로 10영역 커버도 권장 (우선순위 2위).

## 5. 구매 의사결정 흐름 (사용자용)

```
Step 1: [사용자] 공고 PDF 확인 → 직무 트랙 확정 (경영/경제/법 중 어느 것)
Step 2: [사용자] S1 통합 기본서 1권 + S2 트랙별 1권 먼저 구매 (약 5~7만원)
Step 3: [사용자] S3 법령 자료 무료 다운 + PDF 공유
Step 4: [내가] S1/S2 목차·샘플 받아 corpus.import 로 반입
Step 5: [사용자/내가] 1회독 시작, drill 서브커맨드로 회독 추적
Step 6: [사용자] 여력 되면 A1/A3 추가 구매
```

## 7. 박사팀 서명 (가상)
- 공기업 채용 전문가 (15년 실무): S1 해커스 통합 기본서 강력 추천
- NCS 출제 연구자 (박사): 3 유형 대비 필수. 모듈·PSAT·피듈 편중 금지
- 금융법학 박사: 서민금융생활지원법 조문 학습 필수. 무료 자료로 충분
- 회의론자: 대행사 확정 전에 교재 과다 구매 금지. S1 우선 1권 후 확장 권장
- 수석위원 SC1: 모든 추천에 URL 있음 OK. 단, "MID 신뢰도 NCS 3영역" 가정 위에 구축된 우선순위는 공고 원문 검증 후 재조정 필수.
- 수석위원 SC2: 재조정 트리거를 사용자 자료 수령 직후로 설정. 지금 구매는 S1만 권장 (가장 안전).
