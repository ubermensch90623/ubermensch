# 저신뢰 스니펫 모음 (검증 전 사용 금지)

> ⚠ 이 문서의 모든 항목은 **WebSearch 요약 스니펫** 에서 발췌.
> ZERO-TOLERANCE 규칙상 "팩트" 로 취급 금지. 후속 단계(P1 공식 공고 원문 확보 또는 사용자 제공 M1) 에서 검증 후 확정 문서로 이관.
> 단일 WebSearch 결과 기반이므로 작성자·작성일·원문 인용 중 하나라도 누락된 항목은 즉시 기각 대상.

## S1. 과락 기준 (단일 검색 요약)
- 주장: "전공은 각각 40점 이상, 두 과목 평균 60점 이상을 획득해야 과락을 면할 수 있습니다."
- 소스: WebSearch 2026-04-16 쿼리 `"서민금융진흥원" 경영 경제 민법 법학 전공 시험 과목` 요약본
- 검증 상태: **미검증** (원문 출처 URL 불명, WebSearch가 종합 요약한 것)
- 신뢰도: LOW

## S2. 전공 과목 예시
- 주장: "경영 회계, 재무관리, 법학 등의 과목이 포함되어 있으며, 난이도가 상당히 높은 편입니다."
- 소스: 동일 WebSearch 요약
- 검증 상태: **미검증**. "어느 직렬의 전공인지" 불분명 (종합직-일반? 전산직?)
- 신뢰도: LOW

## S3. 역사적 커트라인 수준
- 주장: "합격 커트라인은 약 60~62점 수준으로 알려져 있습니다."
- 소스: 동일 WebSearch 요약
- 참고: 사용자의 2026-04 실제 커트라인은 64.48 (사용자 제공, 신뢰). 과거보다 약간 상승.
- 신뢰도: LOW (수치 범위만 감)

## S4. 직군 구성 (WebSearch 1차 검색 요약)
- 주장: "종합직-일반, 종합직-비수도권, 종합직-장애, 전산직-전산일반, 전산직-정보보호"
- 소스: WebSearch 2026-04-16 쿼리 `서민금융진흥원 2026 종합직 신규채용 공고` 요약본
- 검증 상태: **미검증**. 2026 상반기 공고에 동일 직군 구성인지 미확인 (과거 구성일 가능성)
- 신뢰도: LOW-MID (구조는 그럴듯)

## S5. 전형 순서
- 주장: "서류 전형 → 필기 전형(인성 검사 포함) → 1차 면접 → 2차 면접 → 최종 합격"
- 소스: 복수 WebSearch 요약 언급
- 검증 상태: **미검증**. 일반적인 공기업 전형과 유사하나 인성검사 포함 여부 확인 필요.
- 신뢰도: LOW-MID

## S6. 2022 상반기 경영 필기 "난이도 최상 15문제 기출" 글 존재
- 출처 추정: https://community.linkareer.com/written_test/1658952
- 제목: "[서민금융진흥원] 2022 상반기 경영 필기 후기 난이도 최상 15문제 기출 알려줌"
- 접근: **실패** (403). 본문 미확인.
- 가치: 높음 (접근만 되면 1차에 준하는 후기)
- 권장: 사용자가 해당 페이지 스샷 확보 가능한지 확인

## S7. 휴노 컨설팅 실존 (채용대행 시장 참여)
- 주장: "휴노는 2000년 12월 출범, 심리학 기반 IT 지식회사"
- 소스: WebSearch 요약 (incruit.com 기업정보 페이지 스니펫)
- 서민금융진흥원과의 실제 수의계약 여부: **미확인**
- 신뢰도: 휴노 기업 실존은 HIGH / KINFA 계약 여부는 UNKNOWN
