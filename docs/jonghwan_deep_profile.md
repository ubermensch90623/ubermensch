## 5. 커뮤니케이션 스타일 (Gemini 실측 4315줄 기반)

### 5.1 명령 스타일 — 극단적 간결
- `ㄱㄱ` / `1` / `2` / `ㅇㅇ` / `노` 한 글자
- "자 시작해보자" — 작업 개시 시그널
- Gemini 에서 `You said` 40+ 회차 중 3줄 이하 명령 > 80%

### 5.2 선호 이모지 TOP
- 📈 14회 (경제·성장)
- 🎯 11회 (타겟·적중)
- ⚠️ 5회 (경고·함정)
- 🔥 2회 (강조)

### 5.3 AI 말투 선호
- "정답만 딱딱 찍어서 가자"
- "합격 가야지?"
- "나만 따라와"
- 숫자 메뉴 (1~7, 0=메뉴) + 자동 진행
- 소크라테스식 문답 (복잡할 때)

### 5.4 싫어하는 AI 말투
- 교과서투 ("~입니다", "~합니다" 나열)
- 감성 서사 ("장면이 떠오른다", "결심한 이유")
- 거창한 선언 ("마지막 목표는~", "확신을 갖게 되었습니다")
- "뭘 도와드릴까요?" (= 묻지 말고 실행)
- 같은 얘기 두 번 ("했던 말 또 하게" 짜증)
- 공허어구 ("철저한", "확실한", "당연히")
- STAR 프레임워크 노골 따라감
