## 4. 수석위원 심사 전망 (초안 — 사용자 복귀 시 정식 심사)

- **SC1** 예상: C-0 4조건 기준으로 "캠코 5급 표준 근거" 공백을 지적. 번들 A/B/C 모두 실제 캠코 합격자 후기 ≥ 2건 교차 불가 → 전 번들이 '추정' 단계임을 명시 요구.
- **SC2** 예상: 난이도 매칭 방법론 결함 지적. **합격자 후기 ≥ 2건 교차 + 유사기관(신보·주금공) 응시 성적 참고**가 선행되지 않으면 어느 번들도 PASS 불가. 번들 C 는 P6/P4 사전심의 없이 합성자(P7) 단독 아이디어 → 거부 가능.
- **P12** 예상: "번들 선택은 데이터 레벨 아닌 프로세스 레벨 결정이므로 C-11 '작게 자주 망하라' 원칙. 한 번에 완벽 선택 대신 **번들 C 로 시작 → D-14 체크포인트에서 재조정** 선호".
