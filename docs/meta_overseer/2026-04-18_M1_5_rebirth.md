## §3. 수석위원 SC1/SC2 맹점 지적 (사전 경보)

### 맹점 ① "URL 존재 = 소스 존재" 오판

### 맹점 ② "수정조건부 25건" 을 암묵적 PASS 로 처리
- P6 가 "drop 5 + 수정조건부 25" 로 보고했을 때 SC 가 "drop 안 한 것 = 유효" 로 오독할 위험. **수정조건부 = 수정 전까지는 격리 유지** 가 정확한 해석인데, 수정 과정 자체가 "근거 부재 → 근거 없이 재작성" 이면 상상을 상상으로 덮는 꼴.

### 맹점 ③ P6 self_audit 간과
- P6 가 "본 공격의 재검산도 P6 내적 지식 의존" 고백했는데 SC 가 이를 P6 겸손 수사로 치부하고 P6 판정을 준거로 삼는 순환참조 (SC → P6 → P6 내적).
- 독립 교재 대조(정병열·김판기 등)를 **SC 가 추가로 요구** 해야 하는데 시간 압박으로 생략할 가능성.

### 맹점 ④ 북극성 vs 절차 혼동
- SC 는 "프로세스 정확성" 에 집착 → "이 30문이 북극성 95% 에 기여하는가?" 라는 본질 질문을 놓칠 수 있음. 헌법 북극성 조항의 자문 기능 마비 위험.

### 맹점 ⑤ "격리 상태 유지" 를 최종답으로 오해
