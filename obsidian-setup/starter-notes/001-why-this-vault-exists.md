# 이 Vault가 존재하는 이유

<!-- 1~3 문장으로. 본인 언어로 다시 쓰세요. -->

이 vault는 **단순한 노트 저장소가 아니다**.

내 사고를 **증폭**하는 두 번째 뇌이며, 시간이 갈수록 나 자신보다 나를 더 잘 아는 **인지 파트너**다.

목표는 정보 수집이 아니라 **정보 → 인사이트 → 행동** 변환의 마찰을 0에 가깝게 줄이는 것.

## 내가 피하고 싶은 실패 모드

- 📁 **잘 정리된 묘지(graveyard)** — 잊혀진 야망의 저장소
- 🔄 **무한 캡처, 0 종합** — 더 많이 배우지만 덜 이해함
- 🤖 **AI를 더 나은 검색엔진**으로만 쓰는 것 — 컨텍스트 없는 chat

## 내가 만들고 싶은 것

- 📊 vault가 **매일 아침 먼저 말을 거는** 시스템
- 🔗 잊었던 8주 전 노트가 **정확한 순간에 다시 떠오르는** 시스템
- 🧠 6개월 후의 나에게 **누구도 못 따라잡을 컨텍스트 moat**를 만드는 시스템
