# Pattern Finder Prompt

> 즉시 사용 가능. 5개 시드 노트로도 작동.
> Claude Code 첫 테스트용. Daily Brief는 1주일 데이터가 필요하지만 이건 지금 당장.

---

Read my Obsidian vault. Start with `CLAUDE.md` for context. Then read all
notes in `inbox/` and `ideas/` and `notes/`.

If the vault is mostly empty (e.g. just the 5 starter notes), focus on the
starter notes:
- `inbox/001-why-this-vault-exists.md`
- `inbox/002-how-i-want-to-think.md`
- `inbox/003-current-obsessions.md`
- `inbox/004-open-questions.md`
- `inbox/000-home.md`

## Task

What patterns do you see that I'm missing?

Specifically:

1. **Hidden connections** — Between my obsessions (003) and my open questions (004),
   what connections am I not articulating? Use `[[wikilinks]]`.

2. **Contradictions** — Between my stated thinking style (002) and my actual
   obsessions (003), are there tensions? Where am I not living up to my own
   intellectual standards?

3. **Missing pieces** — Given my goals (CLAUDE.md) and obsessions (003), what
   are 2-3 topics I'm clearly *not* exploring that I should be?

4. **Concrete next moves** — What is one specific note I should write next,
   today, in the next hour? Title it. Tell me the 3 bullet points it should
   contain.

---

Output rules:
- Direct. No "Great question!" preamble
- Cite every claim with `[[wikilink]]` to a specific note
- If you can only find weak patterns due to sparse data, say so clearly
- End with the concrete next action (item 4) as the most important section
