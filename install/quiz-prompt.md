## 요구사항 (그대로 두세요)

위 소스 노트를 읽고, 핵심 개념·정의·인과관계·잘 헷갈리는 함정을 추출해 인터랙티브 HTML 퀴즈를 만들어줘.

**파일 구조**

- single self-contained `.html`, `<!doctype html>`로 시작
- 모든 CSS와 JS는 inline, 외부 CDN 사용 금지
- 다크모드 기본 (배경 `#0C0D11` 톤), 모바일 반응형
- 폰트는 시스템 기본 (`ui-sans-serif`, `ui-monospace`)
- 색은 강조 1개만 (orange `#E87B3C` 권장)

**퀴즈 동작**

- 문제별 카드 UI, 진행률 바
- 객관식: 보기 4개, 클릭 즉시 정답 표시 + 1~2줄 해설
- 단답형: 입력란 + "정답 확인" 버튼 + 정답 + 해설
- 그래프가 필요하면 inline SVG로 (수요·공급 곡선 등)
- 모든 문제 완료 시:
  - 최종 점수 (맞은 수 / 총 수, 정답률 %)
  - 틀린 문제만 다시 풀기 버튼
  - **"결과 JSON 복사" 버튼** — `{ "date": "...", "topic": "...", "score": x/y, "wrong": [...] }` 형식

**콘텐츠 품질**

- 함정 1개씩 의도적으로 섞기 (실제 시험에서 학생들이 자주 틀리는 패턴)
- 해설은 결과만 말하지 말고 **왜** 그런지 1~2줄로
- 정의·공식은 노트의 표현을 우선 (사용자 노트와 어휘 통일)
- 한글로 출제

- 출력 후 지정한 경로에 filesystem MCP로 직접 저장
