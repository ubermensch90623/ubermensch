# ⚡ 신속 TF팀 — 운영 프로토콜

## 개요
상설 조직이 아닌 긴급 대응 임시 조직. CEO가 기존 에이전트를 차출하여 편성하고, 문제 해결 후 해산합니다.

## TF 규칙
- 동시 최대 2개 TF
- 수명 최대 1주
- 결과 문서화 필수
- 해산 후 교훈 전파

## 사전 정의 TF 시나리오

### TF-1: 시험 2주 전 긴급
- **구성**: 복습관 + 출제관 + 전략스카우터 + 번아웃감시관
- **목표**: 최소투입 최대점수
- **전략**: 취약점 포기/선택, 확실한 문제 집중, 시간 배분 훈련

### TF-2: 새 유형 대량 출현
- **구성**: 트렌드분석관 + Gemini외교관 + 출제관 + 교재갱신관
- **목표**: 신유형 긴급 대응
- **전략**: 유형 분석, 풀이법 개발, 연습 문제 생성

### TF-3: 수리 점수 급락
- **구성**: 진단관 + 해설관 + Gemini외교관 + 통계검증관
- **목표**: 원인 진단 + 처방
- **전략**: 오답 패턴 재분석, 기초 재점검, 맞춤 처방

### TF-4: 동기부여 위기
- **구성**: 번아웃감시관 + 습관설계사 + CMO + 출퇴근관
- **목표**: 최소부담 복귀
- **전략**: 학습량 최소화, 성공 경험 설계, 점진적 복귀

```json
  "tf_id": "TF-X",

  "results": "결과",
  "lessons_learned": ["교훈"],
  "system_changes": ["반영할 변경사항"]
}
```
