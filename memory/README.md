# memory/

Durable notes for Claude across sessions. Protocol is in `/CLAUDE.md`.

## Index

| File | Contents |
|---|---|
| `project.md` | Facts about this repo: what it is, how it's laid out, how to run it. |
| `user.md` | Preferences and conventions the user has stated. |
| `decisions.md` | Non-obvious choices with rationale. |
| `gotchas.md` | Mistakes made once, written down so they aren't made again. |

Each file starts empty. Append dated notes at the bottom. Don't rewrite
history; if a note is superseded, add a new dated note that says so.

## What does *not* belong here

- Chat transcripts or session summaries.
- Restatements of what code/docs already say.
- TODOs (use the issue tracker or `TODOS.md`).
- Secrets, tokens, API keys.
