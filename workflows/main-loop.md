# 메인 루프 — 핵심 학습 사이클

## 플로우
```
Keep 원본 → 데이터팀(가공) → 학습팀(실행) → 분석팀(측정) → 피드백팀(개선) → 다시 학습팀
```

## 단계별 상세

### 1단계: 데이터 가공 (데이터팀)
- **트리거**: Keep에 새 메모 추가 / 주간 자동 동기화
- **처리**: 배관공 → 분류사 → 검수관
- **품질 게이트**: 🔴 데이터 검증관 통과 필수
- **출력**: Notion DB에 구조화된 학습 데이터

### 2단계: 학습 실행 (학습팀)
- **트리거**: 매일 아침 (복습관 → 출퇴근관)
- **처리**: 복습 리스트 생성 → 모바일 큐 → 문제 풀이 → 오답 해설
- **품질 게이트**: 🔴 현실성 검증관 통과 필수
- **출력**: 학습 완료 기록 + 오답 데이터

### 3단계: 성과 측정 (분석팀)
- **트리거**: 매일 저녁 / 매주 일요일
- **처리**: 추적관 일일 리포트 → 진단관 패턴 분석 → 예측관 갭 분석
- **품질 게이트**: 🔴 통계 검증관 통과 필수
- **출력**: 일일/주간 리포트 + 취약점 맵

### 4단계: 개선 (피드백팀)
- **트리거**: 주간 리포트 기반
- **처리**: 번아웃 체크 → 워크플로우 개선 → 회의 진행
- **품질 게이트**: 🔴 부작용 검증관 통과 필수
- **출력**: 시스템 업데이트 + 다음 주 학습 방향

### 5단계: 다시 학습팀으로
- 개선된 설정으로 2단계 반복

- 매주 일요일 20:00: 주간 리포트 생성 + 방향 조정 (4단계 트리거)
