# 24/7 자동화 스케줄 (Cowork 예약 작업)

## 일일 자동화

### 매일 아침 06:00 — 오늘 학습 준비
- **담당**: 복습관 → 출퇴근관
- **작업**:
  1. 오늘 복습 예정 항목 수집 (에빙하우스 기반)
  2. 출근길/퇴근길 학습 큐 생성
  3. 컨디션 반영 (전날 학습 여부 체크)
- **출력**: 모바일 최적화 학습 큐

### 매일 저녁 21:00 — 오늘 활동 정리
- **담당**: 추적관
- **작업**:
  1. 오늘 학습 기록 수집
  2. 정답률/시간 집계
  3. 일일 리포트 생성
  4. 연속 학습일수 업데이트
- **출력**: 일일 리포트 (status/daily/)

## 주간 자동화

### 매주 일요일 20:00 — 주간 리포트 + 방향 조정
- **담당**: 분석팀 → CEO
- **작업**:
  1. 주간 성과 집계
  2. 취약점 변화 분석
  3. 다음 주 학습 방향 제안
  4. 번아웃 위험도 평가
- **출력**: 주간 리포트 (status/weekly/)

### 매주 토요일 10:00 — Keep 메모 자동 분류
- **담당**: 데이터팀
- **작업**:
  1. 새로 추가된 Keep 메모 수집
  2. 자동 분류 및 태깅
  3. Notion DB 동기화
  4. 중복 체크
- **출력**: Notion DB 업데이트

## 월간 자동화

### 매월 1일 — 월간 종합 보고
- **담당**: CFO + CEO
- **작업**:
  1. 월간 성과 종합
  2. 합격 가능성 재평가
  3. 전략 대 조정 필요 여부 판단
- **출력**: 월간 보고서
