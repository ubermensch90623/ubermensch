# 외교 루프 — AI간 협업

## 플로우
```
외교팀 ↔ Gemini/Notion AI — 메인 루프 어디서든 호출 가능
```

## 호출 시나리오

### 시나리오 1: 문제 풀이 검증
1. 학습팀에서 답이 불확실한 문제 발생
2. Gemini 외교관 → Gemini에 검증 요청
3. 응답 통합관 → Claude + Gemini 답변 비교
4. 크로스체크관 → 최종 신뢰도 판정
5. 해설관 → 검증된 답변으로 해설

### 시나리오 2: Notion DB 분석
1. 데이터팀/분석팀에서 Notion 데이터 분석 필요
2. Notion AI 외교관 → Notion AI에 분석 요청
3. 결과를 해당 팀에 전달

### 시나리오 3: 개념 교차 검증
1. 경제학 개념의 정확성 확인 필요
2. Gemini + Claude 동시 검증
3. 통합관 → 결과 종합
4. 크로스체크관 → 할루시네이션 체크

## 현재 워크플로우 연계
- 사용자가 이미 Gemini와 소크라테스식 문답 중
- 이 기존 습관을 유지하면서 자동화 보완
