# 연구 루프 — 외부 정보 수집 및 시스템 반영

## 플로우
```
연구팀(외부 조사) → 업데이트팀(시스템 반영) → 메인 루프에 주입
```

## 단계별 상세

### 1단계: 외부 조사 (연구팀)
- **주기**: 격주 (비용/시간 고려)
- **처리**: 전략 스카우터 → 합격자 프로파일러 + 트렌드 분석관 + AI 기술 연구원
- **품질 게이트**: 🔴 정보 신뢰도 검증관 통과 필수
- **출력**: 전략 보고서 + 트렌드 리포트 + 기술 제안서

### 2단계: 시스템 반영 (업데이트팀)
- **트리거**: 연구팀 보고서 완료 시
- **처리**: 전략 업데이터 → 시스템 패치관 + 교재 갱신관
- **품질 게이트**: 🔴 호환성 검증관 통과 필수
- **출력**: 업데이트된 학습 전략 + 시스템 패치

### 3단계: 메인 루프 주입
- 업데이트된 전략/자료가 학습팀에 반영
- CEO 승인 후 적용

## 주의사항
- 연구에 시간 과다 투입 금지 (공부가 본업)
- 변경은 한 번에 1개씩
- 모든 변경은 롤백 가능해야 함
