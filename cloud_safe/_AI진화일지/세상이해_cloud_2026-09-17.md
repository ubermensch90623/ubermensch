## 3. 핵심 패턴 분석

### 패턴 ① 공기업 경쟁률 구조 — 대기업의 2배

서울경제 보도 기준, 공기업 경쟁률은 대기업 공채 대비 2배 수준. 금융공기업 중 특수 기관(항만, 연금 등)에서 수백:1 경쟁률 실제 발생.

| 기관 유형 | 경쟁률 범주 |
|-----------|-------------|
| 금융공기업 (캠코·신보·기보 등) | 추정 100~300:1 구간 (직접 수치 미박제) |
| 비금융 공기업 일부 | 확인: 296:1, 221:1, 176:1 |
| 민간 대기업 | 공기업 대비 절반 수준 (서울경제 비교 보도) |

### 패턴 ② 서류 배수 20배수의 의미

- 최종 선발 1명 자리에 서류 통과자 20명이 필기 경쟁
- 예: 캠코 경영 40명 선발 → 서류 통과 약 800명 필기 응시 추정
- 필기 통과율: 약 5% 이하 (800명 중 다음 전형 진출 인원 대폭 축소)
- **서류 통과가 합격 신호가 아님** — 20배수 서류 통과 후에도 필기에서 95% 탈락 구조

## 4. 종환 방어용 데이터 (구체 수치)

1. **서류 통과 ≠ 합격 신호**: 20배수 구조 → 서류 통과 후에도 필기에서 95% 이상 탈락
2. **캠코 경영 40명 구조**: 지원자 수천 명 → 서류 약 800명 → 필기 → 최종 40명 (각 단계에서 80~95% 탈락)
3. **경쟁률 대기업 2배**: 금융공기업은 안정성 프리미엄으로 민간 대기업보다 지원 집중
4. **NCS > 학벌**: 2025-2026 공기업 취업 트렌드 — 필기·직무 이해도가 결정적 변수
5. **금융공기업 핵심 5**: 기업은행(335명), 캠코(103명), 신보(77명) — 나머지 5개는 소규모
