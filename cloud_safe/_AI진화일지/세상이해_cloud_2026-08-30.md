## 2. 핵심 발견

### 수치 요약 (evidence_gate 통과 항목만)

- **4대 은행 신입 채용**: 2023년 1,880명 → 2024년 1,380명 → 2025년 1,280명 (2년간 -31.9%, -600명)
- **4대 은행 정규직 직원 총수**: 2021년 말 53,173명 → 현재 4,936명(9.3%) 감소
- **금융권 정규직 공고 비중**: 71%(2년 전) → 50%(2026) — 2년새 64% 급감
- **계약직 공고 비중**: 25% → 34% (+9%p)
- **인턴 비중**: 7% → 11% (+4%p)
- **10대 증권사 中 대졸 신입 공채 실시**: 3개사/10개사 (70%가 수시·경력 전환)
- **금융권 공채 박람회**: 82개사 참여(역대 최대) ← '열기' 연출, 실제 신입 자리는 축소

### 구조 진단

1. **AI 전환이 신입 TO를 삭제**: 창구·심사·RM 보조업무 자동화 → 대규모 기수제 공채 불필요. DX 전문직(데이터·AI엔지니어)는 수시·경력으로 흡수.
2. **기간제 증가 메커니즘**: 오프라인 지점 축소 → 잉여 정규직 활용 공간 감소 → 신규는 기간제로 충당 → 퇴직자 재채용(기간제)까지 포함해 수치 부풀림.
3. **박람회 사기 효과**: 참여사 수 최대(82개) 발표로 '취업 기회 확대' 이미지 연출. 실제로는 소규모(10명 이하) 체험형·인턴 중심.
4. **경력직 선호 심화**: 직무 전문성 중심 수시채용 → 신입이 진입할 직무 자체가 감소. 90년생 청년이 가장 직격.
