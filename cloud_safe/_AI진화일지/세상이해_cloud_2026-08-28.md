### 2-1. 계약직→정규직 전환 지원사업 실적 (2026)

| 항목 | 수치 | 비고 |
|---|---|---|
| 2026년 정부 예산 | 69억원 | 고용노동부 정규직 전환 지원 |
| 상반기 목표 인원 | 2,010명 | 전국 |
| 상반기 승인 인원 | 1,247명 | 달성률 63% |
| 승인 사업장 수 | 740곳 | 사업장당 평균 약 1.7명 전환 |
| 지원금 단가 | 월 40만원 (기본) + 월 20만원 (임금 20만↑ 추가) = 최대 월 60만원 | 1년 한도 → 최대 720만원/인 |
| 대상 요건 | 피보험자 30인 미만 기업, 6개월↑ 근무 기간제·파견·사내하도급·노무제공자 | 대기업·공공기관 제외 |
| 지급 신청 단위 | 3개월 단위 | |

**구조적 함의**:
- 상반기 승인 1,247명 ÷ 전국 피지원 규모 비교 시 **극소 규모** — 2025년 8월 기준 비정규직 총수 약 822만명 대비 지원 대상 비율 0.015% 수준
- 30인 미만 기업 제한 → 금융권·공기업 계약직은 지원 대상 **원칙적 제외** (종환 직접 수혜 불가)
- 전환 후 임금 20만원↑ 기준 충족 여부가 추가 지원 관건 → 명목 정규직 전환 후 임금 동결 시 추가 지원 미지급

## 4. 종환 방어용 데이터

- **정규직 전환 지원금 핵심 요건**: 피보험자 30인 미만 사업장 + 6개월 이상 근무 기간제/파견/사내하도급. 금융공기업·대기업 계약직은 **요건 미충족 → 신청 불가**. 사전 확인 필수
- **상반기 실적**: 전국 1,247명 승인 = 전체 비정규직 대비 0.015%. 정부 지원 체감 가능성 매우 낮음 — 제도 홍보 대비 실제 수혜 극소
- **이중 프리케리아트 논거**: 비정규직 + 자산 없는 구조의 청년은 단순 임금 낮음의 문제가 아니라 정신건강까지 복합 타격 → 협상·처우 개선 요구 시 "구조적 이중 위험" 언어로 논거 구성 가능
- **KLIPS 활용법**: 90년생 자신의 경력 경로를 객관화할 때 KLI 데이터 포털(kli.re.kr/klips) 접근 → Smart KLIPS 온라인 분석 도구로 코호트 비교 가능 (회원가입 필요)
- **전환 지원 최대 720만원**: 사업주 대상 인센티브 — 계약직 당사자가 "전환 요청 시 사업주에게 720만원 지원된다"는 사실을 협상 카드로 활용 가능 (30인 미만 사업장 해당 시)
