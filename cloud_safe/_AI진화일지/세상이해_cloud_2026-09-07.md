## 3. 핵심 발견 요약

### 3-1. 노동진입 지연 구조 (BOK 제2026-2호)

- **첫 취업 1년 이상 소요**: 2004년 24.1% → 2025년 **31.3%** (7.2%p 상승)
- **평균 첫 취업 소요기간**: 2004~2013 취업세대 18.7개월 → 2014~2023 취업세대 **22.7개월** (+4개월)
- **졸업 즉시 취업 비율**: 17.9% → **10.4%** (절반 가까이 감소)
- 90년생 (만36세, 2026 기준) = 2012~2016년 노동시장 진입 코호트 → 진입 지연 가속 구간에 해당

### 3-2. 자산배제·부채 구조

- **청년층 부채비중**: 2012년 23.5% → 2024년 **49.6%** (전체 연령 대비, 2배 이상)
- 주거비 1%p 상승 → 교육비 지출 **0.18%p 감소** (생존형 지출 구조 고착)
- 주거비 1% 상승 → 총자산 **0.04% 감소** (자산 형성 경로 차단)
- 소득·자산 최하위 청년 **5년 새 2배 증가** (AI 대체·집값 복합 요인, 한국일보 2026-06-11)

### 3-3. '쉬었음' 인구 구조 (BOK 제2026-3호)

- 19~34세 '쉬었음' 인구: 2003년 20만 명대 → 2024년 **40만 명 초과** (2배 증가)
- 실업자 통계에서 제외되는 잠재실업 — 취업포기·구직단념 포함

### 3-4. 이중 프리케리아트 논문 (보건사회연구 46(2), 2026)

- **이중 프리케리아트 정의**: 노동불안정(비정규·계약직·저임금) + 자산배제(주거빈곤·무자산·부채 과부하) 동시 해당
- 이중 조건 충족 시 단일 조건 대비 정신건강 악화 효과 가중 (우울·불안 지표)
- 구체 % 수치는 PDF 직접 접근 필요 — 이번 세션에서도 proxy 차단으로 내부 수치 미확보 (갭 유지)
- 청년 70% 부모 동거 ('캥거루족') = 자산배제의 사회적 적응 전략으로 해석 가능
