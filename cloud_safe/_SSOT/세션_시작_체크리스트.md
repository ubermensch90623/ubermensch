# 세션 시작 체크리스트 (Claude Code · Cowork 공통)

> **목적**: Claude Code와 Cowork 세션이 다른 세션임에도 **동일한 맥락에서 시작**하게 만든다.
> **근본 문제**: 종환이 한 세션에서 준 피드백이 다른 세션으로 이어지지 않던 메모리 분절 현상.
> **해결**: 모든 세션은 시작 시 이 체크리스트를 실행한다.

---

## 🎯 진입 조건 판별 (30초 이내)

세션 시작 시 종환의 첫 메시지에 아래 키워드가 있으면 해당 카테고리 프로토콜 실행:

| 키워드 | 카테고리 | 필수 로드 파일 |
|--------|----------|----------------|
| 자소서, 자기소개서, 제출, 인크루트, 접수 | **자소서** | [[자소서_피드백_누적]] + 제출본 PDF 아카이브 |
| 채용, 마감, 공고, D-day, 모니터링 | **채용** | [[채용_D2룰]] + `harness_state.json` |
| 메모리, 분절, SSOT, 동기화 | **메모리** | [[메모리_동기화_아키텍처]] |
| 시험, 필기, NCS, 경제학, 경영학, 상업경제 | **학습** | `03_학습/00_종환_통합프로토콜.md` |
| 시험 복원, 헌법, 북극성, P1~P11, ubermensch | **복원** | `작업/ubermensch/CLAUDE.md` + `docs/audit-v3.md` |

**키워드 없음 = 일반 대화**. 체크리스트 간략 버전만 실행.

## 📤 세션 종료 프로토콜

종료 시 반드시 실행:

1. **핸드오프 파일 작성**: `agent-memory/handoffs/YYYY-MM-DD_HHMM_<topic>.md`
   - 이번 세션 결정사항 3줄
   - 다음 세션이 이어야 할 것 3줄
   - 미해결 블로커 리스트
2. **피드백 누적 append**: 새 피드백 있으면 [[자소서_피드백_누적]] 또는 해당 SSOT에 append
3. **Git commit**:
   ```bash
   cd ObsidianVault
   git add -A && git commit -m "session <topic> <date>"
   git push 2>/dev/null || true
   ```
4. **boot_state.md 자동 갱신**: Stop hook이 처리 (수기 편집 금지)

## 🧪 이 체크리스트 자체의 QA

이 파일이 제대로 작동하는지 확인하는 법:

- 종환이 **같은 피드백을 두 번째 주면** → 이 체크리스트 실패 사례.
- 해당 피드백이 있는 SSOT 파일을 추적해 "왜 세션 시작 시 안 읽혔는지" 근본 원인 분석.
- 분석 결과를 이 파일에 반영.
