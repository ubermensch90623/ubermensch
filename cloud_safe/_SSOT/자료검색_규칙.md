# 자료 검색 규칙 (UNVIOLABLE)

> 종환 명령 (2026-04-27): "너 내가 앞으로 자료 검색하라고하면 일반 자료 보지마"
> 누적 실수 5건의 근본 원인 = 일반 자료(블로그·콘텐츠) 우선 인용
> 이 파일은 모든 검색·답변·박제의 사전 게이트로 작동

---

## §1. 금지 출처 (NEVER 인용)

| 카테고리 | 예시 | 사유 |
|---|---|---|
| 일반 블로그 | tistory·brunch·naver blog 일반 | 검증 불가 |
| 콘텐츠 사이트 | safehomes·burgundx·notturnoworld·bravilife | 마케팅·SEO 글 |
| 법률 정보 사이트 (공식 외) | lawform·yesform·a-ha·albup | 2차 가공 |
| 카페·커뮤니티 | naver cafe·다음 카페·디씨 | 익명 |
| 자동 요약·집계 | 위키·나무위키 단독 | 1차 출처 아님 |
| 영문 일반 매체 | medium·substack | 한국 법 미적용 |

→ 위 출처에서 정보 발견해도 **"근거 후보"이지 "출처"가 아님**. 반드시 공식 1차 출처로 검증해야 인용 가능.

### Tier 2 — 전문가 본인 채널 (검증 후 인용 가능)
| 형식 | 조건 |
|---|---|
| 유튜브 | 변호사 본인 채널 (변호사 자격 명시), 로펌 공식, 정부·기관 공식 |
| X (Twitter) | 변호사·전문가 본인 계정 (실명·자격 노출) |

| 칼럼 | 한겨레·중앙·조선·법률신문 등 주요 신문 법률·부동산 데스크 기명 |

→ Tier 2 인용 시 **"누가·어디서·언제·자격증명"** 4가지 명시.

### Tier 3 — 보강 (Tier 1·2 없을 때만)
일반 자료는 보강 인용만 가능. 핵심 주장은 Tier 1·2에서.

## §3. 검색 규칙

1. **검색어 최우선**: `site:khug.or.kr` `site:law.go.kr` `site:scourt.go.kr` `site:moel.go.kr` 등 공식 도메인 한정
2. **filetype:pdf** 우선 (약관·매뉴얼 1차)
3. 일반 검색 결과는 **링크만 보고 도메인 검증 후** fetch
4. blog·tistory·cafe·brunch·medium·통합 콘텐츠 사이트 → 자동 필터

## §4. 위반 시

- 일반 자료를 출처로 인용 시 → 종환 신뢰 즉시 손실, 케이스 망칠 위험
- 박제 파일에 일반 자료 출처 발견 시 → 즉시 정정·해당 결론 재검증
