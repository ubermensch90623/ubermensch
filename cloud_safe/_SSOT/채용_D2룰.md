# 채용 D-2 룰 — 프로액티브 알림 파이프라인

> **목적**: 종환이 매일 recruit 사이트를 직접 들여다보지 않게. AI가 먼저 발견하고 알린다.
> **원칙**: "D-0에 긴급하게"가 아니라 "D-7에 편하게". 버퍼를 시스템으로 강제.
> **최종 업데이트**: 2026-04-22 (IBK캐피탈 D-0 긴급 이슈 이후)

---

## 🎯 핵심 원칙

1. **종환 ≠ 모니터**. AI가 매일 스캔하고 D-day 계산해서 알림.
2. **D-2 완료 강제**. 자소서 작성은 마감 2일 전 마감. D-0 긴급 작업 금지.
3. **자동 초안 스텁 생성**. 공고 발견 즉시 자소서 파일 뼈대 생성.
4. **버퍼가 사라지면 경보**. D-2 미완 공고는 빨간불.

## 🛠 구현 설계

### 1. 스케줄러 (이미 사용 가능)
- `mcp__scheduled-tasks__create_scheduled_task` MCP 사용
- 매일 07:30 실행: `recruitment_ops.py --mode=daily-alert`

### 2. 입력 데이터 소스
| 소스 | 주기 | 내용 |
|------|------|------|
| `site_registry.json` | 반영구 | 관심 기관별 채용 URL |
| `harness_state.json` | 매일 갱신 | 지원 확정 공고 목록 + 상태 |
| `incruit.com` 스크래핑 | 매일 | 수협·IBK캐피탈 등 신규 공고 |
| `nhi.go.kr`, `lh.or.kr` 등 | 매일 | 직접 공고 페이지 |
| `CLAUDE.md §2` | 수기 | 현재 지원 현황 (종환 검증) |

### 3. 출력 채널 (우선순위)
1. **Desktop/.claude/boot_state.md** — 매 세션 시작 시 종환이 봄
2. **agent-memory/handoffs/YYYY-MM-DD_daily_alert.md** — 세션 핸드오프
3. **데스크톱 알림** (차후 구현) — Windows toast notification
4. **이메일** (차후 구현) — shekhar90623@gmail.com

### 4. 게이트 로직 (pseudocode)
```python
# recruitment_ops.py --mode=daily-alert
today = date.today()
for posting in registered_postings:
    d_day = (posting.deadline.date() - today).days
    if d_day == 14 and posting.status == "지원확정":
        create_stub(posting)
    if d_day == 7:
        progress = check_draft_progress(posting)
        if progress < 0.5:
            alert(f"⚠️ D-7: {posting.name} 진척 {progress*100:.0f}%")
    if d_day == 2:
        if not is_draft_complete(posting):
            alert(f"🚨 D-2: {posting.name} 미완! 오늘 완료 필수")
    if d_day == 1:
        run_jaso_validator(posting)
    if d_day == 0:
        alert(f"🔴 D-0: {posting.name} 오늘 {posting.deadline.time()} 마감")
```
