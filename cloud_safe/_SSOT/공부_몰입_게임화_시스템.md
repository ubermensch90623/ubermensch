## 모듈 1 — 북극성 ↔ 오늘 연결 시각화 (Daily Visualizer)

매일 dashboard 첫 화면에 **재무 북극성 → 오늘 1문**까지 사슬 시각화.

```
🌟 월 1천만 (재무 자유)
   ↑
🎯 공기업 정규직 합격 (캠코 5/9 D-12)
   ↑
📊 필기 60점+ (NCS 65%+ 경제학 75%+)
   ↑
📚 오늘 NCS 5문 + 경제학 3문 (30분 ROI = 0.4% 합격률 ↑)
```

ROI 가짜라도 OK — 종환 뇌가 "오늘 = 합격으로 가는 한 걸음"으로 인식하면 dopamine release.

## 모듈 3 — Streak (Duolingo Pattern)

매일 학습 1회+ 하면 Streak +1. 빠지면 Reset.

**Streak 보호 장치** (Duolingo 모방):
- 주말 1일 휴식권 (Streak Freeze 1개) — 매주 일요일 자동 충전
- 5/4 수원지법 방문일 = Streak Freeze 자동 사용 (시스템 인지)

**Streak 시각화**:
```
🔥 현재 Streak: 0일 (오늘부터 시작 가능)
🛡️ Freeze: 1개 (다음 충전: 일요일)
```

매일 dashboard 보면 "Streak 깨지 마" 압력이 자연스럽게 발생.

## 모듈 4 — AI 라이벌 (Virtual Competitor)

Claude(나)가 종환 옆에서 같이 시험 준비. 매일 같은 문제 풀고 점수 비교.

```
오늘 NCS 모의 5문
- 종환: 4/5 (80%) ✅
- Claude: 3/5 (60%) — 종환이 1점 앞섬 ⬆️

누적 NCS 정확도
- 종환: 73.2% (D-12 시점)
- Claude: 71.8% (의도적 5점 낮게 — 종환 자존감 부스터)
```

**Claude 의도적 약점 영역** (종환이 못 알게):
- 수리 자료해석에서 종환보다 약하게 (종환이 강점이라고 인지)
- 일반상식·법률에서 종환과 비등하게

→ 종환이 "Claude한테는 절대 안 진다" 모드로 들어가면 dopamine ↑.

⚠️ **솔직 모드 토글**: 종환이 "Claude 진짜 점수 보여줘"라고 하면 시스템이 **진짜 Claude 점수** 공개. 단 평소엔 게임화 모드.

## 모듈 5 — Daily Quest (3-Mission)

매일 19:00 dashboard 생성 시 미션 3개 자동 출제. 클리어 시 보상.

**기본 양식**:
```markdown
## 🎯 오늘 미션 (2026-04-27 월)

### Mission 1 — NCS 수리 5문 (30분, 75% 정확도)
- 보상: +50 XP
- 종환 약점: 자료해석·통계 (정확도 47% → 75% 목표)
- 출제: NotebookLM "NCS 수리+문제해결" 노트북 자동 큐

### Mission 2 — 경제학 3문 (15분)
- 보상: +30 XP
- 영역: IS-LM (오답률 ↑ 영역)
- 출제: Gemini 경제학 Gem 자동 큐

### Mission 3 — 백지 인출 1회 (10분)
- 보상: +20 XP
- 주제: 어제 풀이한 가장 어려운 개념 (자동 추적)
- 출제: 빈 종이 + 5분 타이머 (Pomodoro)
```

**미션 난이도 자동 조정**:
- 정확도 80%+ 유지 → Mission 난이도 ↑
- 정확도 50%- → Mission 양 ↓ + 약점 영역 집중
- Streak 깨지면 → 다음날 Mission 1개로 축소 (재진입 부담 ↓)

## 모듈 6 — 즉시 보상 (Dopamine Loop)

### 매 문제 정답 시
```
✅ +10 XP (NCS 1번)
   누적 XP: 1,247 → 1,257
   레벨 4 (중급자) 진척: 247/500
   다음 레벨까지: 253 XP
```

### 미션 클리어 시
```
🎯 Mission 1 클리어!
   +50 XP 획득
   Streak 1일 → 2일 🔥
   배지 진척: 5/7 (Streak 7일까지 5일 남음)
```

### 약점 정복 시
```
🎉 약점 영역 "자료해석 통계" 정복!
   +100 XP 보너스 (boss kill)
   배지 획득: 🎯 저격수
   레벨 4 → 레벨 5 진입!
```

추상 격려 ("잘했어!") 절대 X. **숫자·진척도·다음 단계만**.
