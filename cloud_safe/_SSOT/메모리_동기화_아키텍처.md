# 메모리 동기화 아키텍처 — Claude Code ↔ Cowork SSOT

> **근본 문제**: 동일 파일시스템을 공유하지만 세션 로그가 분리되어, 한쪽에서 받은 피드백이 다른 쪽으로 전달되지 않음.
> **해결**: ObsidianVault를 공동 SSOT로 두고 세션 시작/종료에 hook으로 동기화.
> **레퍼런스** (2026-04-22 리서치): Karpathy LLM Wiki · claude-memory-compiler · obsidian-mind · agent-memory (shidoyu)

---

## 🎯 설계 원칙

1. **SSOT는 파일이다**. 세션 로그나 메모리 서버가 아니라, **사람도 읽을 수 있는 마크다운**.
2. **위치는 하나다**. `Desktop/작업/ObsidianVault/_SSOT/`. 중복 금지.
3. **쓰기는 commit으로 강제**. 파일 수정 후 git commit 없으면 다음 세션이 모른다.
4. **읽기는 hook으로 강제**. 세션 시작 시 SSOT를 안 읽으면 차단.
5. **CLAUDE.md = 북극성**. Desktop 루트 CLAUDE.md는 양쪽 세션이 반드시 첫째로 읽음.

## 🪝 Hook 구현 스펙

### SessionStart (양쪽 공통)

**Claude Code**: `.claude/settings.json` 의 `hooks.SessionStart`
**Cowork**: 세션 시스템 프롬프트에 "/세션_시작_체크리스트 실행" 명시

```python
# .claude/hooks/session_start.py
import os, subprocess, sys

VAULT = os.path.expanduser("~/Desktop/작업/ObsidianVault")

def pull():
    if os.path.isdir(os.path.join(VAULT, ".git")):
        subprocess.run(["git", "-C", VAULT, "pull", "--rebase"], check=False)

def emit_context():
    parts = []
    for path in [
        os.path.expanduser("~/Desktop/CLAUDE.md"),
        os.path.expanduser("~/Desktop/.claude/boot_state.md"),
        os.path.join(VAULT, "_SSOT/세션_시작_체크리스트.md"),
        os.path.join(VAULT, "_SSOT/자소서_피드백_누적.md"),
    ]:
        if os.path.isfile(path):
            with open(path, encoding="utf-8") as f:
                parts.append(f"### {os.path.basename(path)}\n\n{f.read()}")
    print("\n\n---\n\n".join(parts))

if __name__ == "__main__":
    pull()
    emit_context()
```

> stdout은 Claude Code가 추가 컨텍스트로 주입. Cowork는 동등한 체크리스트를 시스템 프롬프트에서 실행.

### SessionEnd / Stop

```python
# .claude/hooks/session_end.py
import os, subprocess
from datetime import datetime

VAULT = os.path.expanduser("~/Desktop/작업/ObsidianVault")

def commit():
    if not os.path.isdir(os.path.join(VAULT, ".git")):
        return
    subprocess.run(["git", "-C", VAULT, "add", "-A"], check=False)
    msg = f"session {datetime.now():%Y-%m-%d %H:%M}"
    subprocess.run(["git", "-C", VAULT, "commit", "-m", msg], check=False)
    subprocess.run(["git", "-C", VAULT, "push"], check=False)

if __name__ == "__main__":
    commit()
```

## 🌐 Git Remote 전략

### 옵션 A (권장): GitHub Private Repo
- 생성: `gh repo create ubermensch-obsidian --private`
- 원격: `git remote add origin ...`
- Claude Code local(Windows)과 Cowork mount(Linux) 양쪽이 동일 remote 사용
- **진짜 SSOT**: 다른 기기/세션이 같은 git 상태를 봄

### 옵션 B: Local git only
- Remote 없이 ObsidianVault 자체가 git repo
- Claude Code와 Cowork가 같은 물리 파일시스템을 보기 때문에 local 변경으로 충분 (단, 세션 타이밍 주의)

## 🧯 파티션 탐지 & 복구

다음 조건 중 하나면 파티션 발생 가능:

- 종환이 동일 피드백을 2번째 받음
- SSOT 파일 한쪽에만 존재하고 다른 한쪽에서 안 보임
- `git status` 에 오랜 uncommitted 변경 있음
- `handoffs/` 폴더에 24시간 이상 된 가장 최신 파일

**복구 프로토콜**:
1. 어느 쪽에서 분기가 났는지 git log로 추적
2. 분기 지점의 결정사항을 [[자소서_피드백_누적]] 또는 해당 SSOT에 통합
3. 이 파일에 실패 사례 섹션 추가
4. [[세션_시작_체크리스트]] 에 재발 방지 체크 추가
