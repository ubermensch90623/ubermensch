## 트리거 (자동 가동)

종환 발화 키워드 감지 시 즉시 가동 (동의 묻지 않음):

| 키워드 | 트리거 |
|---|---|
| "자료 찾아·찾아봐·검색·조사" | 풀 파이프라인 가동 |
| "유튜브" + 도메인 키워드 | YouTube transcript 추출 + 매핑 |
| "공식 자료·전문가" | Tier 1·2 한정 검색 |
| "한계 해결·방법 찾아" | X·GitHub·Reddit 신뢰 도메인 검색 |
| "박제해·기록해" | 결과를 _SSOT 또는 _AI진화일지로 자동 저장 |

## 6단계 파이프라인 (현재 가동)

```
[검색] → [필터] → [추출] → [요약] → [박제] → [매칭]
   ↓        ↓        ↓        ↓        ↓        ↓
WebSearch  도메인  yt-api   Claude   _SSOT   종환_케이스
+site:.go.kr 화이트  1.2.4    분석    _AI진화  cross-link
```

### 1. 검색 (WebSearch)
- 검색어 prefix: `site:.go.kr OR site:.or.kr OR site:.ac.kr` 우선
- 영상 검색: `site:youtube.com "변호사" + 케이스 키워드`
- 학술: `arxiv.org` `scholar.google` `riss.kr`

### 2. 필터 (자료검색_규칙.md §2 적용)

✅ 통과 (Tier 1·2):
- `.go.kr` `.or.kr` `.ac.kr` `.edu`
- `arxiv.org` `pubmed` `nature.com` `plos.*` `science.org`
- `khug.or.kr` `scourt.go.kr` `law.go.kr` `iros.go.kr` `courtauction.go.kr`
- `youtube.com` (단, 채널 검증 후 — 변호사 본인·기관 공식)
- `github.com` (개발 영역만)
- `reddit.com` (개발·기술 sub만 — r/MachineLearning·r/LocalLLaMA·r/programming)
- `x.com` (전문가 본인 계정만)
- `huggingface.co`

❌ 차단 (BLOG_DOMAINS — evidence_gate에서 강제):
- 일반 블로그·콘텐츠 사이트 (35개 도메인 BLOCK 등록됨)

### 3. 추출 (이미 설치된 도구)
| 도구 | 버전 | 용도 |
|---|---|---|
| youtube-transcript-api | 1.2.4 | 자막 있는 영상 (한국어 우선) |
| yt-dlp | 최신 | 영상 메타·다운로드 |
| pdfplumber·pypdf·pypdfium2 | — | PDF 추출 |
| Tesseract | 5.4 (kor.traineddata) | 이미지 OCR |
| PaddleOCR | 3.4.1 | 한글 OCR 백업 |

### 4. 요약 (Claude 자체 분석)
- transcript에서 종환 lived·진행 케이스 키워드 추출
- 시점별 핵심 인용 (`00:30 — "이런 경우 보증사고"`)
- 종환 케이스 적용 가능 부분만

### 5. 박제 (자동 위치)

| 영역 | 박제 위치 |
|---|---|
| 종환 진행 케이스 | `_SSOT/{케이스명}.md` 또는 신규 파일 |
| 학습 raw 결과 | `_AI진화일지/{도메인}_YYYY-MM-DD.md` |
| Transcript 풀버전 | `Desktop/.tmp_yt_transcripts/{video_id}.txt` |
| 시스템 메타 | 이 파일 또는 `_SSOT/AI_도구_로드맵.md` |

### 6. 매칭 (cross-link)
- 영상 인용 → 박제 파일 footnote
- 종환 lived 발화 ↔ 외부 자료 자동 매칭 (world-learning-loop 23:45)
- 일요일 23:30 nightly-autoresearch가 신규 영상 ↔ 진행 케이스 매칭
