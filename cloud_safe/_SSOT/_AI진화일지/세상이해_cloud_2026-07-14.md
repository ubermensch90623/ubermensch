## 3. 주요 패턴 분석

### 3-1. 신고 3배 증가 vs 처벌 0.6% — 구조적 무력화
- 6년간 신고 3배 증가했으나 실효 제재(과태료+송치) = 2%대
- 검사 기소유예 25% → 행위자 면죄부 기능
- **사업주가 행위자인 경우** 기존 구조: "사장한테 신고하면 사장이 조사" → 2026.04 개정으로 일부 개선

### 3-2. 비정규직 갑질 = 생존권 협박형
- 정규직 대비 비정규직 피해율 +9%p (41.3% vs 32.3%)
- 메커니즘: "내가 뽑았으니 자를 수 있다" — 계약 종료 위협이 갑질 수단으로 작동
- 신고 못 하는 이유: 계약 갱신 / 재취업 레퍼런스 박탈 공포
- 퇴사 선택 23.7% = 피해자가 오히려 일자리 잃는 역설

### 3-3. 2026.04 정책 변화 — 실효성 미검증
- 사업주·사업경영담당자 행위자 시 근로감독관 선제 직접 조사 도입
- 아직 시행 초기 → 처리율 개선 여부 6개월 내 추적 필요

### 3-4. 연구 기반 심리 피해
- 직장내괴롭힘 → 우울증 (여성 더 취약, PMC 2023)
- 괴롭힘 → 일-가정 갈등 매개 → 삶의 질 하락 (누적 경로)
- 호텔·서비스업 소진(burnout) 연구 별도 확인
