## 2. 핵심 발견 — 구조 분석

### 2-1. 5대 은행 비정규직 증가 추이 (evidence_gate 통과 수치)

```
5대 은행 전체 직원 중 비정규직 비중 추이

2021년 6월:   9.8%
2022년:       9.9%  (+0.1%p)
2023년:      10.9%  (+1.0%p)
2024년 6월:  11.3%  (+0.4%p)

3년간 누적:  +1.5%p 증가
```

→ 정규직 채용 문은 좁아지면서, **비정규직 포지션이 그 빈자리를 채우는 구조**  
→ "계약직으로 먼저 들어가 보자"는 전략이 은행 쪽에서는 구조적으로 정착 중

### 2-2. 은행 신규 채용 수치 (3년 연속 감소)

| 연도 | 5대 은행 연간 신규 채용 |
|------|----------------------|
| 2023년 | **1,880명** |
| 2024년 | **1,270명** (△610명, -32.4%) |
| 2025년 | **1,215명** (△55명, -4.3%) |

→ 2023→2024 단 1년에 32% 급감  
→ 5대 은행 전체에서 연간 1,200여 명 = 은행당 평균 240명 수준  
→ 금융공기업(캠코·주금공·예보 등) 포함 시 전체 파이 재계산 필요

### 2-3. 연령 현실 — 비공식 장벽 구조

| 항목 | 현실 |
|------|------|
| 공식 나이 제한 | 대부분 폐지 (법적 차별 금지) |
| 실제 신입 평균 나이 | **28~29세** (링커리어 커뮤니티 다수 게시물 수렴) |
| 30대 중반(36세) 신입 지원 시 | "서류 통과 후 면접에서 불이익" — 비공식 구조 존재 |
| 중고신입 수요 증가 | 인턴·계약직 경험자 중고신입 형태 증가, 평균 연령 소폭 상승 추세 |

**구조 해석**: 공식 제한은 없지만 평균 신입 나이 28~29세 기준으로 면접관 시각에서 30대 중반은 "설명이 필요한 이력" 취급. 갭 이어·계약직·이직 경력이 있으면 서류 통과 후 면접에서 "왜 지금?"을 매번 소명해야 하는 구조.

### 2-4. 계약직→정규직 전환의 실제 (농협 사례)

- 신청자 800명 이상, 경쟁률 **6:1**
- 전환 방식: **신규 채용 형식** (계약직 근무 기간 경력 불인정)
- 전환 후에도 계약직 시절 호봉·경력 리셋 적용 사례 존재

→ 계약직 기간이 정규직 전환 시 불이익 아닌 '무(無)'로 처리됨  
→ 계약직 진입은 전환 보장 없는 대기열 진입일 뿐

### 2-5. 2026 금융권 공동채용 박람회 — 구조적 의미

- **12개 은행** 공동 참여
- 서류평가 공동 솔루션으로 1회 평가 → 여러 은행 면접 기회
- 출처: https://financejobfair.co.kr/

→ 단발성 공채보다 **통합 접근 경로** 존재 — 개별 지원보다 레버리지 높음  
→ 다만 서류 탈락 시 12개 은행 전체에서 동시 탈락 구조이기도 함
