## 2. 핵심 발견 — 30대 계약직 이직 경로 구조

### 2-1. 정규직 전환율 — 연령대별 수치

| 구분 | 3년 후 정규직 전환율 | 비고 |
|------|---------------------|------|
| 25~34세 비정규직 | **33%** (세 명 중 한 명) | 출처 B snippet |
| **35~59세 비정규직** | **12.5~14.3%** (7~8명 중 한 명) | 출처 B snippet — 종환 해당 연령대 |
| 동일 사업장 전환 | **5% 미만** (2024년) | 출처 A snippet — 2010년대 초 10%에서 절반 이하 |

**해석**: 종환(90년생, 35세)은 35~59세 구간에 해당. 3년 후 정규직 전환 확률 **약 13%** — 비정규직 7~8명 중 1명만 3년 안에 정규직 이동 성공. 동일 사업장 경로는 추가로 차단되어 있어(5% 미만) 외부 이직이 사실상 유일한 경로.

**수치 주의**: snippet 경유 간접 확인. 직접 PDF 미접근. 수치 ±3~5%p 오차 가능. 후하게 해석 금지.

### 2-2. 이직 경로 구조 분해

```
계약 만료 후 이행 경로 (수치 확인 가능 vs 미확인):

경로 1: 동일 사업장 정규직 전환 — 5% 미만 (출처 A)
경로 2: 외부 이직(비정규직→정규직) — 35세 이상 3년 내 약 13% (출처 B)
경로 3: 외부 이직(비정규직→비정규직) — 잔여 경로. 수치 미확인
경로 4: 동일 사업장 재계약 — 고용노동부 조사 존재하나 수치 미취득 (출처 E 403)
경로 5: 고용종료·비경활 이동 — 수치 미취득

총계 확인: 경로 1+2 합산 ~18%. 나머지 82%는 재계약 또는 비정규직 지속.
→ 구조 해석: 계약 만료 후 정규직 이동은 소수 경로. 대다수는 재계약(비정규직 유지) 또는 타 비정규직 이동.
```

출처 E(사업체기간제근로자현황조사) 직접 수치 미취득 — 재계약·종료 비율 확정 불가.

### 2-3. 임금 격차 — 이직 성공 시 예상 임금 개선

| 고용형태 | 시간당 임금 지수 (300인 이상 정규직=100) |
|----------|----------------------------------------|
| 300인 이상 사업체 정규직 | **100** |
| 300인 이상 사업체 비정규직 | **64** |
| 300인 미만 사업체 정규직 | **71** |
| 300인 미만 사업체 비정규직 | **49** |

출처: 2024 KLI 비정규직 노동통계 C (2024년 8월 기준) — WebFetch 403, snippet 간접.

**해석**: 계약직(비정규직)이 300인 이상 사업체 정규직으로 이직 성공 시 **시간당 임금 +56%** 상승 기대. 공공기관 정규직(대형 사업장) 이직 시 가장 큰 임금 개선. 단, 전환 성공 확률 13%(35~59세 3년 내)와 교차 적용 필요.

**기대값 추정** (비공식, 수치 조합):
- 3년 내 정규직 이직 성공 확률: ~13%
- 성공 시 임금 지수 상승: +36~56%p (이직 대상 사업체 규모에 따라)
- 3년 비정규직 유지(재계약) 확률: ~82% (잔여 추정)
- 비정규직 유지 시 임금 변화: 경험칙상 소폭 인상 or 동결

## 3. 종환 방어용 데이터

| 항목 | 수치 | 방어 활용 |
|------|------|----------|
| 35~59세 3년 내 정규직 전환율 | **~13%** | 이직 전략 현실 기대치 설정 — "3년 안에 정규직"이 13%임을 인식, 과도한 낙관 경계 |
| 동일 사업장 전환율 | **5% 미만** | 현 직장 내 정규직 전환 기대치 낮게 설정 — 외부 이직 병행 전략 필수 |
| 비정규직 임금 지수 | **64 (정규직=100)** | 계약직 유지 시 매년 36%p 임금 손실 지속. 이직 타이밍 판단 기준 |
| 이직 성공 시 임금 지수 상승 | **+36~56%p** | 금융공기업 정규직 이직 성공 시 예상 처우 개선 규모 — 공고 비교 시 참고 |
| 계약 만료 전 적정 구직 시작 | 3~6개월 전 | 법적 의무 없으나, 고용 공백 최소화 위해 선제적 활동 필요 |

**구체 방어 루트**:
1. 계약 만료 6개월 전 → 금융공기업(캠코·HF·근복 등) 채용 공고 모니터링 시작
2. 계약 만료 3개월 전 → 국민내일배움카드 등록 (work24.go.kr) — 실업 후 훈련 연계
3. 계약 만료 직전 → 재계약 가능성 서면 확인 요청 (묵시적 갱신 방지, 갱신기대권 발생 여부 확인)
4. 동일 사업장 정규직 전환 기대 금지 (5% 미만 — 외부 이직이 주경로)
