| 행정직 | 59.7% | **40.3%** | 29.5세 |
| 기술직 | 71.7% | 28.3% | — |

- 2023→2024 행정직 30대 이상 합격 비율 +1.2%p 증가
- 공무원과 공기업(공공기관)은 채용 구조 상이 — 직접 전환 불가하나 방향성 참고 가능
- **공기업 별도 연령대별 합격 통계 공개 없음** (ALIO 집계는 성별·장애인·지역인재 중심, 연령별 공개 미확인)

## 3. 90년생(1990년생, 36세) 공기업 취업 구조 분석

### 시간 압박 요인

| 요인 | 내용 |
|------|------|
| 나이 경쟁 | 공기업 나이 제한 폐지(2019~) 이후에도 현직자 증언: "실질 합격자 평균 연령 25-28세" (Tier 3) |
| 공채 감소 → 쏠림 | 민간 공채 43% 감소 → 20대 수험생 공기업 몰림 → 36세 상대적 경쟁 열위 |
| 경력 기간 | 계약직 경력 다수 보유 → 경력직 채용 vs 신입 공채 포지션 전략 선택 필요 |
| 필기 vs 경험 | NCS 필기는 나이 무관하나 면접 인상·조직 적합성에서 30대 중반 불이익 가능성 |

### 수비 데이터 (종환 방어용)

1. **30대 이상 합격자 40.3%**: 구조적 차단 아님 — 공무원 기준이지만 공기업도 유사 방향성
2. **30대 합격 비율 1.2%p 연속 증가**: 2022→2023→2024 상승 추세 → 시간이 지날수록 30대 합격 풀 확대
3. **공기업 쏠림으로 경쟁 증가 = 필기 절대 점수 중요**: NCS 필기 고득점이 연령 불이익을 상쇄 가능 (채용담당자 인터뷰 다수 사례 — Tier 3 범주)
4. **경력직 채용 트랙 병행**: 공기업 경력직(L3~5년 경력 요건) — 계약직 경력을 활용하는 별도 트랙 존재
