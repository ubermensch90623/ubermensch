## 2. 핵심 발견

### 2-1. 신고 건수 급증 vs 실제 보호의 괴리 (출처 A WebSearch 요약)

| 지표 | 수치 |
|------|------|
| 2019년 진정 접수 | 약 **2,100건** |
| 2024년 진정 접수 | 약 **1만 1,000건** |
| 증가 배율 | 약 **5.2배** (5년간) |

**구조적 해석**: 신고 건수 급증 = 인식 확산 + 채널 정착. 그러나 5/29 세션 확인 수치: **가해자 처벌율 2.8%(2022)**와 대비 → 신고해도 처벌 안 되는 구조 그대로 유지. 특히 계약직에게는 신고 이후 계약 미연장이 가장 현실적 보복 수단이지만, 이를 "불이익 처우"로 입증하기 위한 증거 기준이 높아 사실상 구제 공백 존재.

### 2-2. 계약직 신고 억제 메커니즘 — 구조 분석 (출처 A·B·C 종합 + 법리 구조)

**왜 계약직은 신고를 못 하는가 — 4중 억제 구조**:

1. **계약 만료 = 자연 종료 = 불이익 입증 불가**  
   근기법 76조의3 6항 "해고·불이익 처우 금지" 적용 → 그러나 계약 만료 후 미연장은 "해고"가 아니라 "계약 종료"로 처리 가능. 사용자가 "계약 기간이 종료됐을 뿐"이라 주장 시 신고와 인과관계 입증이 피해자 부담.

2. **5인 미만 사업장 2025년 하반기 이전 적용 제외**  
   비정규직·계약직 다수 종사하는 소규모 사업장이 법 적용 사각지대. 출처 B 확인 — 2025 하반기부터 확대 적용됐으나 기존 피해는 소급 불가.

3. **내부 조사 주체 = 사용자 (5인 이상 직접 고용 기준)**  
   사업주가 조사 의무 담당 → 계약직 피해자 신고 시 사업주 입장에서 "있는 대로 조사"할 유인 없음. KCI 논문 C는 조치 의무 위반의 판단 기준 연구 — 실무 쟁점 자체가 복잡함 확인.

4. **신고 후 취업 불이익 (레퍼런스 차단)**  
   계약직→정규직 전환·타사 이직 시 전 직장 평판 조회 관행 — 신고 이력은 "문제 직원" 낙인으로 작동 가능 (사례 근거: WebSearch 요약 내 계약직 사례 언급).

### 2-3. 비정규직 규모와 취약성 (출처 E)

| 지표 | 수치 | 출처 |
|------|------|------|
| 비정규직 비율 (2025, 정부) | **38.2%** | KOSIS/매일노동뉴스 |
| 비정규직 비율 (2025, 노동계) | **41.0~41.5%** | 동상 |
| 절대 규모 추정 | 취업자 약 2,700만 기준 → **1,030만~1,120만명** | 역산 추정 |

**시사**: 직장내 괴롭힘 피해 가능 모집단의 38~41%가 신고 억제 구조 내에 있음. 신고 급증(5.2배)이 구조 개선처럼 보이나, 실제 피해 경험자 중 신고율이 여전히 매우 낮을 가능성 (한국노동연구원 언급 14% 경험률 → 신고 건수 11,000건 대비 취업자 2,700만 × 14% ≈ 378만명 경험자 추정 → **신고율 약 0.3%** — WebSearch 요약 수치 조합, 산술 추정, Tier 3 신뢰도).

### 2-4. 2026년 4월 개정 핵심 (출처 B WebSearch 요약)

- 5인 미만 적용 확대 (2025 하반기) 이후 후속 개정
- 2026년 4월 방향: 처벌 강화 및 신고 보호 범위 확대 시도
- 로톡뉴스 기사 존재 확인 — 구체 조항 미추출 (접근 미시도)

**한계**: 개정법 효력은 신고 후 계약 미연장 보복에 대한 **입증 책임 전환 여부**가 핵심인데, WebSearch 요약에서 해당 조항 확인 불가.

## 4. 종환 방어용 데이터

| 데이터 | 활용 |
|--------|------|
| 2024년 진정 11,000건 (5.2배 증가) | "신고는 급증했지만 처벌율 2.8% — 신고 자체가 보호 수단은 아님" |
| 계약 미연장 = 법적 불이익 입증 난이도 높음 | 신고 전 **증거 확보(문자·카카오·녹취) 및 날짜 기록 선행** 필수 |
| 5인 미만 2025 하반기 적용 확대 | 소규모 직장 피해자도 이제 신고 채널 존재 — 단 처벌 집행은 별개 |
| 비정규직 38~41% 규모 | 자신이 구조적으로 다수 집단 — 개인 실패가 아닌 시스템 문제 |
| 신고율 추정 0.3% (산술) | 신고 안 하는 게 비겁한 게 아니라 합리적 자기보호 — 신고 시 증거+노무사 필수 |

**실전 대응 순서** (증거 있을 때):  
1. 내부 신고 이전에 **증거 디지털 보관** (카카오 백업, 녹취파일 외부 저장)  
2. 신고서는 **날짜·행위·목격자** 3요소 포함  
3. 계약 만료 예정 시 신고 타이밍 = 만료 3개월+ 이전 또는 만료 후 노동위 구제  
4. 노무사 무료 상담: 고용노동부 노동포털 or 서울노동포털 (출처 F)
