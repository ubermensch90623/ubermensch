## 2. 핵심 발견 — 계약직 계약 미연장 보복 × 법적 대응 구조

### 2-1. 계약 미연장 = 보복 성립 법리 구조

| 단계 | 조건 | 근거 |
|------|------|------|
| 갱신기대권 인정 | 반복 갱신 + 기간 규정이 형식에 불과 | easylaw.go.kr 법령 해석 |
| 갱신 거절 무효 | 정당한 사유 없는 거절 → 해고와 동일 | 대법원 판례 법리 |
| 보복 인과관계 | 신고일–계약 종료일 시간적 근접성 + 갱신 거절 사유 불합리 | 직장내 괴롭힘 보복 판단 기준 |
| 구제 루트 | 노동위원회 부당해고 구제신청 OR 차별시정 신청 | 노동위원회 7,712건 (2024) |

**핵심 조건**: 갱신기대권이 성립하려면 ① 2회 이상 반복 갱신, ② 갱신 거절 통보가 직전 신고·이의제기와 시간적으로 근접해야 한다. 단순 1년 계약 만료는 갱신기대권 주장 어려움.

### 2-2. 불이익처우 처벌 통계 — 고용형태별 분리 통계 부재 확인

| 항목 | 수치 | 비고 |
|------|------|------|
| 2024 노동위원회 총 권리구제 | 7,712건 | 심판 7,648 + 차별시정 64 |
| 차별시정 사건 비율 | 64 / 7,712 = **0.83%** | 비정규직 차별 시정 이용률 극히 낮음 |
| 고용형태별 불이익처우 처벌 건수 | **통계 미공개** | 고용노동부 행정 내부 집계로 외부 접근 불가 (계속 갭) |
| 직장내 괴롭힘 신고 후 가해자 처벌률 | 2.8% (2022) | 6/21 세션 확인 수치 — 최신 통계 업데이트 미확인 |

## 4. 종환 방어용 데이터 (구체 수치)

1. **갱신기대권 요건**: 2회 이상 반복 갱신 시 갱신기대권 성립 → 계약 미연장 시 부당해고 구제신청 가능
2. **보복 입증 패키지**: ① 신고일 기록 + ② 계약 종료 통보일 기록 + ③ 기존 갱신 관행 증거(이전 계약서, 이메일) + ④ 갱신 거절 사유의 불합리성 (합리적 사유 없음 입증)
3. **노동위원회 차별시정**: 2024년 64건 처리. 0.83%이지만 실제 신청 후 인용률은 별도 확인 필요 — 진입 장벽 낮음 (비용 무료)
4. **공익신고자보호법 병용**: 공기관 예산 부정·안전 위반 신고 + 계약 미연장 보복 → 두 법 동시 적용 가능 (6/27 확인)
5. **5인 미만도 2025 하반기부터 보호**: 소규모 사업장도 직장내 괴롭힘 신고 루트 열림
