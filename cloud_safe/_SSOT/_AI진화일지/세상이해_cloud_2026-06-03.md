## 종환 방어용 구체 데이터

1. **캠코 초봉 기준점 확정**: 2026년 일반직 초봉 3,584만원. 현재 비정규직 월 208.8만원(연 2,505만원) 대비 연 1,079만원 증가 = 3년 누적 3,237만원 처우 개선 규모. 이직 타이밍 판단 시 기회비용 계산 기준으로 사용 가능.

2. **금감원 채용 규모 추정**: 2025년 신입 5급 70명. 금융권 공기업 중 규모 있는 채용처. 캠코 불합격 시 차선 경로로 2026 9월 공고 일정 확인 필요 (~09/08 마감 확인).

3. **비정규직 경력 인정 근거**: 공무원보수규정 별표 16에 유사경력 환산율 규정. 공공기관 경력직 지원 시 계약직 경력을 "유사경력"으로 인정 요구 가능. 단, 기관별 내규로 달라지므로 채용공고 "경력산정 기준" 조항 반드시 확인.

4. **NCS 블라인드 전략**: 캠코 NCS 채용은 연령·학벌 불기재 원칙. 30대 계약직이 스펙 경쟁에서 불리한 신입 공채보다 유리한 구조. 직무 실무 경험 서술 중심 자기소개서 전략 유효.

5. **ALIO 경력직 필터 활용**: job.alio.go.kr에서 "경력직" 필터로 금융 공공기관 경력직 공고 모니터링 가능. 캠코·금감원 외 추가 경로 확보 수단.
