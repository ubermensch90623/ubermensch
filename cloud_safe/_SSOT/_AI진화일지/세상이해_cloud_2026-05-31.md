## 2. 핵심 발견 — 비정규직 직업훈련 접근성 구조

### 2-1. 훈련 참여율 격차 (현존 최신 공개 수치)

| 연도 | 비정규직 훈련 참여율 | 정규직 대비 격차 |
|------|---------------------|----------------|
| 2007 | 18.6% | 미확인 |
| **2011** | **27.8%** | **-11.7%p** |
| 2023~2025 | 공식 분리 수치 미공개 | WebFetch 전량 403 |

출처: KRIVET 비정규직 교육훈련 성과분석 (A) — 2011년 데이터. 2024년 KLI 비정규직 노동통계 PDF 접근 403 반복으로 최신 수치 미확인.

**해석 주의**: 2011년 이후 능력개발카드제 확대(2007~)로 참여율 수치 자체는 올랐을 수 있으나, 정규직 대비 격차 축소 여부는 미확인. 수치 후하게 적용 금지.

### 2-2. 차별시정 제도 — 수치로 본 실효성

```
비정규직 856만명 (2025년 기준)
  ↓
차별시정 신청: 159건 (2023년) — 전체의 0.002%
  ↓
신청 후 취하: 24.5% (2023년)
  ↓
실제 노동위원회 판정까지: 극소수
  ↓
이유 구조:
  (1) 비교대상 근로자 찾기 어려움 (기간제법 좁은 범위)
  (2) 입증 책임 피해자 부담
  (3) 보복 우려 (취하 24.5%의 주요 원인)
  (4) 기간제법 개정안 5건 계류 중 — 미통과
```

출처: 매일노동뉴스 B (WebSearch snippet 인용) — 직접 WebFetch 불가 → 간접 인용, 수치 신뢰도 Tier 2.

**구조 해석**: 법조문상 교육훈련 차별 금지(E)가 있어도, 신청율 0.002%는 법이 작동하지 않음을 증명. '신고할 수 있다'는 권리와 '신고할 수 있는 현실' 사이 괴리.

### 2-3. 국민내일배움카드 — 개인 단위 훈련 지원 실용 구조

| 항목 | 내용 |
|------|------|
| 대상 | 비정규직·실직자·구직자 (재직자 포함) |
| 한도 | 최대 500만원 (5년) |
| 자부담 | 15~45% (취약계층 0%) |
| 생계 보장 | 훈련장려금 (한국형 실업급여 연계) — 별도 신청 필요 |
| 한계 | 직장 다니면서 훈련 = 시간 부족. 계약직 특성상 계약 기간 중 훈련 이탈 어려움 |

출처: C (work24.go.kr 공식)

**함의**: 제도는 존재하지만 ①시간 ②정보 접근 ③계약 종료 압박이 실질 이용 장벽.

### 2-4. 차별 구조 요약도

```
[계약직 근로자]
  → 사업주 훈련: 기업 재량 → 정규직 위주 배분
  → 기간제법 차별금지: 교육훈련 포함 → 신청율 0.002% (유명무실)
  → 국민내일배움카드: 이론상 활용 가능 → 시간·정보 장벽
  → 결과: 역량개발 비용 개인 전가 + 기간 내 이직 어려움
         → 계약 만료 후 재취업 경쟁력 열위 고착
```

## 4. 종환 방어용 데이터 (구체 수치)

1. **차별시정 신청 가능 항목**: 교육훈련 기회, 복지시설 이용, 임금·상여금 — 기간제법 제8조 근거. 단, 신청 효과 기대치 낮게 유지 (인용 데이터 미확인, 취하율 24.5%)

4. **직업훈련비 지원 우선 도메인**: 금융·회계·데이터 분석·NCS 직무 관련 훈련과정 — 캠코 등 금융공기업 취업 역량과 연결 가능.
