## 2. 구조 분석

### 산재 은폐 전체 규모

- **은폐율**: 전체 산재의 66.6% 은폐 (2021년 연구 추정치, Tier 2)
- **미처리 비율**: 최소 54.8%~93% (2014년 국민권익위원회 의결서)
- **적발 현황**: 5년간 4,146건 미보고 적발, 과태료 257억 3,400만원
- **처벌율**: 4년간 은폐 41건 + 미신고 3,805건 → 2.5%만 처벌

### 사업주 은폐 동기 4가지

1. 노동부 집중 감독 지정 → 사업장 운영 부담
2. 산재보험료 개별실적 인상 (재해율 ↑ → 보험료 ↑)
3. 대외 이미지 손상 (언론 노출, 거래처 신뢰 저하)
4. 입찰자격 심사 감점 (공공조달·건설업 직격)

### 비정규직이 더 취약한 이유 3중 구조

| 취약 요인 | 수치 근거 |
|-----------|-----------|
| 산재보험 미가입 18.3% | 비정규직 산재보험 가입률 81.7% (정규직 94.5%) → 신청 경로 자체 차단 |
| 노조 가입률 1.0% | 정규직 13.1% 대비 1/13 → 집단 압력 없음 → 사업주 공상처리 압박 수용 |
| 고용불안 (계약해지 위협) | 계약 미연장 위협 실효 — 법적 불이익 입증 난이도 높음 (6/6 세션 확인) |

### 공상처리 메커니즘 작동 순서

```
산재 발생
    ↓
사업주 → 공상처리 제안 (치료비·급여 보전 약속)
    ↓
비정규직 → 계약해지 우려 + 노조 없음 + 신고 절차 무지
    ↓
공상처리 수용 → 산재 기록 없음 → 보상 불완전
    ↓
계약 만료 후 → 직업병·장해 발생 시 소급 입증 불가
```

### 전체 산재 현황 (맥락)

- 2024년 사고사망자: 589명(553건), 전년 대비 9명(-1.5%) 감소
- 2025년 3분기 누적: 457명(440건), 전년 동기 대비 14명(+3.2%) 증가
- 2024년 비정규직 규모: 845.9만명 (전년 대비 33.7만명 급증)
- 2024년 비정규직 임금: 정규직의 66%

## 4. 종환 방어용 데이터

| 데이터 | 활용 |
|--------|------|
| 산재 은폐율 66.6% | "사업주의 공상처리 권유는 관행이 아니라 위법 은폐 — 응하면 미래 보상 차단" |
| 처벌율 2.5% | 처벌 안 받는다고 합법이 아님 — 산안법 제57조 은폐 금지 조항 실재 |
| 산재보험 미가입 18.3% | 입사 시 산재보험 가입 여부 확인 필수 (비가입 시 사업주 위반) |
| 노조 1% | 집단 압력 없으므로 개인 증거 확보가 유일 방어 수단 |
| 과태료 257억 실적 | 신고하면 사업주에게 실질 불이익 발생 — 협상 레버리지 |

**실전 대응 순서** (부상·직업병 발생 시):
1. 사업주가 공상처리 제안해도 거절 — 거절 의사 문자·카카오로 서면화
2. 근로복지공단 직접 신청 (산재보험 가입 여부 무관하게 신청 가능, 미가입 시 사업주 제재)
3. 진단서·재해경위서·목격자 진술 즉시 확보
4. 계약 미연장 위협이 신고 이후 발생하면 → 불이익 처우로 별도 진정 (6/6 세션 증거 확보 루트 연결)
5. 공익신고자 보호법 적용 여부 노무사 무료 상담 선행
