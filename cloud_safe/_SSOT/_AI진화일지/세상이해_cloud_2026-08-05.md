## 2. 핵심 발견 — 구조 분석

### 2-1. 법의 숫자 구조 (evidence_gate 통과 수치만)

```
신고 → 처벌 깔때기 (2025년 기준)

신고 접수:     16,373건  (100%)
과태료:           231건  (1.4%)
검찰송치:         101건  (0.6%)
  └ 기소유예:      27건  (27% of 송치, 전체의 0.16%)
  └ 실제 기소:     52건  (전체의 0.32%)
```

→ **신고 98.6%는 실질적 처벌 없이 종결**

### 2-2. 신고 안 하는 이유 (2025 조사)

| 이유 | 비율 |
|------|------|
| "대응해도 나아질 것 같지 않아서" | 47.1% |
| "인사상 불이익 우려" | 30.1% |
| 기타 | 22.8% |

→ 신고 선택 자체가 이미 **피해자 책임** 구조

### 2-3. 역고소 패턴 (2026 MBC 취재)

신고 직후 가해자·사측이 피해자에게:
- 명예훼손 고소
- 사문서위조 고소 (사례: 신고 이틀 후)

법적 대응: 개인 사법권 행사는 막을 수 없음  
→ 피해자가 **피의자 신분으로 수사·재판 병행** 감당  
→ 2026년 개정 후에도 역고소 차단 조항 없음

### 2-4. 사측 역논리 부상 (2026-08-03 한경)

"신고자 보호만큼 오·남용 신고도 제재해야" — 가해자 측 프레임:  
→ 신고 억제 효과 의도된 담론  
→ 증거 없어도 역고소 후 "상호 갈등" 프레임으로 무마 가능

### 2-5. 정신건강 복합 손상

- 2024년 수일간 우울감: **40.2%** (2022년 30% → 2년 만에 +10.2%p)
- 심각한 스트레스: **46.3%** (2022년 36% → +10.3%p)
- 갑질 경험자 심리 반응: 짜증·예민 45.8%, 분노·억울함 19.1%
- TELUS Health 2025 Q2: 한국 직장인 정신건강 지수 아시아 최저권

→ 갑질 → 신고 못함 → 정신건강 악화 → 번아웃·이직 → 재취업 불리 의 복합 경로
