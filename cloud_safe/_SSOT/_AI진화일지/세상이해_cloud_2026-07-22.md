## 2. 핵심 발견 요약

### 2-A. 공공기관 갑질의 역설적 면죄부 구조

공공기관은 직장내 괴롭힘 법 위반으로 과태료를 받은 비율이 **0.48%** — 민간기업 1.61%의 3분의 1 수준. 이는 공공기관이 괴롭힘이 적어서가 아니라:

- 공공기관은 자체 인사위원회·감사실 운영 → 외부 신고를 내부에서 흡수
- "잘 대응한 것처럼 보이면" 노동청 조사 없이 종결 가능
- 민간위탁 구조에서 수탁기관은 원청(공공기관) 눈치 → 피해자 2중 억압

결론: **공공기관 갑질은 더 조직적으로 은폐되는 구조.**

### 2-B. 계약직 신고 장벽 = 생존권 담보 협박

```
신고 시나리오 (비정규직):
  1단계: "내가 뽑았으니 자를 수 있다" → 신고 자체를 막음
  2단계: 신고해도 40%는 부당처우 (해고·계약해지·왕따)
  3단계: 계약해지 = 근로기준법 제76조의3 위반이지만 입증 난이도 高
  4단계: 부당처우 시정 기간 14일 내 시정 시 처벌 없음 → 사실상 면책
```

비정규직은 계약해지가 '해고'가 아닌 '계약만료'로 포장되기 때문에 법적 구제 경로 자체가 막힘.

### 2-C. 2026-07-02 허위신고 제재 신설 — 피해자에게 불리한 역효과 가능성

2026-07 매뉴얼 개정으로 **허위신고 제재 기준**이 신설됐다. 이는:

- 가해자 측이 피해자의 신고를 "허위신고"로 역고소하는 무기로 활용 가능
- 계약직 피해자는 역고소 리스크까지 감수해야 하므로 신고 장벽 추가 상승
- 2024년 신고 12,253건 중 2% 미만이 실제 처벌로 이어지는 구조에서 제재 역방향 적용 우려
