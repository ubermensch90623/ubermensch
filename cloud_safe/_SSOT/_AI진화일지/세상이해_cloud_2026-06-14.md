| 2023 | ~20,500명 추정 | ▼~18% | 공공의료기관 채용 축소 주요 요인 (Tier 2 요약) |

- 인더스트리뉴스 헤드라인 "매년 20%씩 감소" — 연속 감소 기조 확인, 정확 % 는 Tier 2

### 감소 배경 (검색 요약 종합)

1. **정원 총량 규제 강화**: 기재부 공공기관 방만경영 기조 → 정원 동결·축소 지침
2. **코로나19 완화**: 공공의료기관 한시 증원 해소 (2023 주요 감소 요인)
3. **디지털화**: 주요 공기업 자동화 도입 → 신규 TO 창출 억제
4. **2026 방향**: '직무중심·블라인드' 기조 유지. 디지털·ESG 분야 전략 채용 소폭 증가, 퇴직 증가에 따른 기존 인원 대체 채용 일부 유지

## 3. 금융공기업 블라인드 채용과 연령 실태

### 블라인드 채용 주요 제도

| 항목 | 내용 |
|------|------|
| 학교 명칭 | 미기재 (블라인드) |
| 나이·졸업연도 | 미기재 |
| 외모 관련 정보 | 사진 미첨부 |
| 평가 기준 | NCS 직업기초능력 + 직무전공 + 역량면접 |
| 캠코 공식 발표 | "나이·학교·영어점수 미반영" 명시 (Tier 1) |

### 합격자 연령 실태

- 서울경제 보도: 블라인드 채용 이후 **30대 후반~40세 신입 등장** (Tier 2 언론)
- 블라인드 익명 증언: 금융공기업 신입 **30대 초중반 다수** (Tier 3, 정량 아님)
- 공인회계사 2024 최종 합격자 평균 연령 **26.9세** — CPA 경로는 상대적으로 낮은 연령 (Tier 1, 고시위크)

> 금융공기업 신입 '평균 나이' 공식 통계 미존재 — ALIO 공개 항목에 없음. 연령 분포 데이터 직접 확인 불가.

### KDB 산업은행 경쟁률 참고 (2022, 구형)
- 하반기 115명 선발, 지원 3,416명 → 경쟁률 **29.7:1**
- 2024~2026 갱신 수치 미확보 (채용 페이지 직접 조회 필요)
