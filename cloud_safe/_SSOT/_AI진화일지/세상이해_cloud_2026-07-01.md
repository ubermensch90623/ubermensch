## 2. 핵심 발견

### 2-1. 직장내 괴롭힘 신고 처리 구조 — 실제 수치 확정

| 지표 | 수치 | 출처 |
|------|------|------|
| 2024년 신고 처리 건수 | **12,253건** | 농민신문 2025-02-18 |
| 2024년 신고 접수 건수 | **13,601건** | 매일노동뉴스 (접수 기준, 처리 건수와 차이) |
| 법 위반 판정율 | **12.4% (1,458건/12,253건)** | 농민신문 2025-02-18 |
| 가해자=사업주 비율 | **26.7% (2022~2025.8 누적)** | 매일노동뉴스 |
| 연도별 추이 | 2020: 5,823건 → 2021: 7,774건 → 2022: 8,961건 → 2023: 11,038건 → 2024: 12,253건 | 농민신문 |

**구조 해석**: 신고 건수는 6년간 2.1배 증가(5,823→12,253). 그러나 법 위반 판정은 12.4%에 고착 — 신고 증가가 구제율 상승으로 이어지지 않는다. 가해자가 사업주인 경우 26.7%는 1/4 이상의 신고가 근로기준법 109조 형사처벌 대상 구조임에도 처벌 실적은 2.8%(2022년 확인 수치)에 머무름.

**수치 불일치 주의**: 12,253건(처리)과 13,601건(접수)의 차이는 연도 경계 처리 방식 차이로 추정. 두 수치 모두 신뢰할 수 있으나 '처리'와 '접수' 구분 명기 필요.

## 4. 종환 방어용 데이터

1. **신고 처리 현실 수치**: 법위반 판정 12.4% — 형사 처벌보다 고용노동부 시정명령·과태료 루트가 실효 루트. 검찰 송치 후 실제 기소율은 별도 추적 필요.

2. **가해자=사업주 루트 핵심**: 26.7% 케이스에서 내부 조사 경로 막힘(사업주가 가해자 = 조사 위임 불가). 이 경우 고용노동부 직접 진정이 유일한 루트 — 1544-1350 고용노동부 고객상담센터.

3. **처리기간 대응**: 75.3일 = 보호 조치 신청 즉시 + 고용노동부 진정 동시 제출로 두 채널 병행. 계약 종료 예정일 전 조치 신청 날짜 선점이 핵심.

4. **프리랜서 사각지대 예외 적용**: 이데일리 판결 — 실질 지휘·감독 관계(업무 지시·시간·장소 통제)가 인정되면 프리랜서도 예외적으로 적용 가능. 이메일·메시지로 구체적 지시 기록 보관 시 근로자성 주장 근거.

5. **공익신고 병용 확인**: 공기관 내 예산·절차 위반 목격 케이스라면 공익신고자보호법(493개 법률 위반) 적용 여부 선확인 후 권익위 신고(www.clean.go.kr) 제출 — 75.3일 보호사건 처리 루트와 별도 트랙.
