### 2-3. 실업급여 수급 장벽: '재계약 제안 거부' 함정

```
[사용자 행동 패턴]
계약 만료 2주 전 → "재계약 의사 있음" 통보 (구두·문자)
→ 근로자가 재계약 거절
→ 고용센터: "자발적 이직" 처리 → 실업급여 수급 자격 박탈

[실제 활용 방식]
- 열악한 조건(임금 미인상·업무 변경)으로 재계약 제안
- 거절하면 실업급여 X
- 수용하면 착취 지속
= 사실상 실업급여를 지렛대로 한 재계약 강요
```

## 4. 종환 방어용 데이터

### 4-1. 실업급여 수급 자격 자가 체크리스트

```
□ 이직 전 18개월 내 고용보험 피보험 180일 이상인가?
  → 계약직 이력 여러 개면 피보험 기간 합산 확인 필요
  → 공백 기간(고용보험 미가입) 있으면 18개월 역산 주의

□ 계약만료로 이직하는가?
  → 사용자가 재계약 의사를 "먼저" 밝혔는가?
  → 만약 재계약 제안이 왔다면 = 거절 시 자발적 이직 처리됨
  → 대응: 재계약 제안 내용·조건·일시 반드시 문서화

□ 재계약 제안이 열악한 조건이라면?
  → '재계약 제안=사실상 계약 변경'으로 구직급여 인정 가능 판례 존재
  → 단, 고용센터 인정 여부 불확실 → 사전 상담 필수
```

### 4-2. 사회보험 가입 확인법 (계약직 현재·이력)

```
국민건강보험공단 앱 '건강보험' → 직장가입자 이력 조회
고용산재보험 토탈서비스 (total.comwel.or.kr) → 고용보험 피보험 이력 확인
  → 피보험 기간 합계가 180일 이상인지 확인
  → 미가입 기간 있으면 실업급여 수급 가능 시점 역산
```

### 4-3. 금융공기업 준비 중 계약직 이력 전략 시사점

- 고용보험 피보험 기간 공백 최소화 → 향후 계약 종료 시 실업급여 안전망 확보
- 전일제 비정규직 고용보험 가입율 개선 추세 → 계약직 직장이 고용보험 가입 여부 채용 시 확인 필요
- 시간제·단기 알바 이력 있다면 보험 이력 직접 확인 후 공백 파악
