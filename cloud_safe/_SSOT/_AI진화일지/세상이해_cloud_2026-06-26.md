## 2. 구조 분석: 신고→제재 단계별 이탈 지도

```
[전체 피해자 100명 가정]
        │
        ▼ 신고율 15.3%
   15.3명 신고
        │
        ├─ 취하: 31.0% → 4.7명 (보복 두려움·불리한 합의 압박·포기)
        ├─ 법위반없음: 29.2% → 4.5명 ("이건 괴롭힘 아님" 처리)
        └─ 실질 처리 진입: 5.9명 (38.8%)
                │
                ├─ 개선 지도: 10.34% → 1.6명 (권고 수준, 강제력 없음)
                ├─ 과태료: 1.29% → 0.2명
                └─ 검찰 송치: 1.83% → 0.3명
                        └─ 기소 (송치 중 42.6%): 0.13명

결론: 100명 중 어떤 형태로든 제재 도달 = 약 2.1명 (2.1%)
```

### 이탈 지점별 원인

**이탈 1: 신고 전 차단 (84.7%)**  
- 비정규직: 계약 종료 = 즉각 생계 박탈 → "신고=자폭"으로 인식  
- 정규직 피해자도 임원급 가해자는 신고 자체 포기  
- 경향신문: "절반이 참거나 모른 척" — 절반은 신고 의향조차 없음

**이탈 2: 취하 (31%)**  
- 사측 압박·불리한 합의 유도  
- "신고해봐야 아무것도 안 된다" 학습된 무력감  
- 2024.5까지 11,998건 = 하루 평균 **약 7건 취하**

**이탈 3: 법위반없음 (29.2%)**  
- "직장 내 괴롭힘 성립" 요건 협소: 업무상 필요성·사회 통념 예외 적용 남용  
- 근로감독관 판단 재량 큰 구조 → 지역별·담당자별 편차  
- 11,301건이 이 유형 — **신고한 사람 셋 중 하나가 "그건 괴롭힘 아님" 통보**

**이탈 4: 개선지도 (강제력 없음)**  
- 4,005건 중 이행 확인 구조 취약  
- 가해자 직접 처벌 없이 "사업장에 주의" 수준

**구조적 공백: 가해자 무처벌**  
- 근로기준법 76조의2~3: 사용자 조치 의무만 규정  
- **가해자 개인 형사처벌 조항 없음** — 2026.4 개정 후에도 동일  
- 과태료 501건의 대상 = 가해자가 아닌 **사용자(회사)**
