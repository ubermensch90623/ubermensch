## 2. 핵심 발견

### 2-1. Dark Triad 구조 확정

```
나르시시즘 (Narcissism)
  - 과도한 자기애, 칭찬 욕구, 비판 과민
  - 초기 인상: 자신감·매력적으로 보임 → 실제 착취 관계로 전환

마키아벨리즘 (Machiavellianism)
  - 목적 위해 타인 조종, 계산적 대인관계
  - 감정 조작·정보 비대칭 활용에 능숙

사이코패시 (Psychopathy)
  - 낮은 공감, 높은 충동성
  - CWB(반생산적 업무행동) 효과크기: 3요소 중 가장 큼 (메타분석)
```

**한국 직장 연구 확인**: 3요소 모두 CWB와 정(+) 인과관계. 단일 요소가 아닌 조합 발현이 현실.

### 2-2. 조직 구조가 갑질을 만든다 (개인 심리 아님)

```
갑질 설명력:
  조직 요인 (위계문화, 침묵 규범, 묵인 관리자) : 개인 요인 = 2:1 ~ 5:1

핵심 메커니즘:
  1. 권력 차이가 인지되면 → 가해자 억제력 감소 (조직이 허용 신호)
  2. 피해자 신고율 15.3% (5/21 확인) → 가해자 학습: "해도 괜찮다"
  3. 공공기관 특성: 연공서열 + 신분 이원화(정규직↔계약직) → 구조적 권력 차이 고착
```

### 2-3. Dark Triad 가해자 식별 패턴 (실무 적용)

| 초기 단서 | 중기 단서 | 방어 포인트 |
|-----------|-----------|-------------|
| 지나치게 매력적·카리스마 | 약자에게만 다른 태도 | 첫 3개월 관찰 필수. 초기 인상 ≠ 실체 |
| 성과·공을 독점하려는 패턴 | 비판 시 과잉반응 (나르시) | 문서화 선행. 구두 지시 안 받기 |
| 정보 선택적 공유 | 감정·인맥 무기화 (마키아) | 증인 확보. 단독 공간 회피 |
| 공감 없는 빠른 결정 | 이슈 발생 시 피해자화 (사이코) | 신고 가능한 채널 사전 파악 |

> 출처 근거: E(kormedi) 행동 패턴 + C(worklaw) 조직 메커니즘 + A/B(학술) CWB 연구

### 2-4. 공공기관 계약직 특유 취약성

- **신분 이원화**: 정규직(갑) vs 계약직(을) → Dark Triad 가해자에게 권력 격차 구조 제공
- **침묵 규범 강화**: 계약직은 재계약 인질 → 신고율 15% 이하 (정규직 대비 더 낮을 가능성, 직접 연구 수치 미확인)
- **방어 한계**: 근기법 76조의3(불이익 처우 금지) 존재하지만, 계약직은 "재계약 거부"로 우회 가능 → 법적 방어선 취약
