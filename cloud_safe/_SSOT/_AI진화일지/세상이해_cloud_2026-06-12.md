## 3. 갑질 처벌 깔때기 구조 시각화

```
피해자 모집단 (100%)
    │
    ▼ 신고 15.3% (나머지 84.7% 침묵 — 6/6 신고 억제 구조)
신고·진정 접수 (2024: 12,253건)
    │
    ├──── 취하 ~30% → 사실상 '협상 취하' 또는 보복 두려움
    ├──── 법 위반 없음 ~28% → 입증 실패
    ├──── 개선 지도 ~10% → 과태료·형사처벌 없음
    │
    ▼ 인정(처벌) 12% (2024 기준)
과태료·검찰 송치 (5년간: 501+709=1,210건)
    │
    ▼ 검찰 송치 709건 → 기소 302건 (송치 대비 42.6%)
기소 (전체 신고 대비 0.78%)
    │
    ▼
실형·벌금 (집계 미상 — 이후 큐 등록)
```

**해석**: 피해자가 신고를 결심해도 → 처벌(과태료 이상)로 연결되는 비율 12%. 형사 기소까지 가면 0.78%. 신고 억제(6/6)와 처벌 부재(6/12)가 맞물려 가해자 억제력 사실상 0 구조.

## 4. 법적 구조 — 처벌 규정 한계

| 위반 유형 | 처벌 | 비고 |
|-----------|------|------|
| 괴롭힘 행위 자체 | **형사처벌 없음** | 과태료 최대 1,000만원만 |
| 사용자 조치의무 위반 | 과태료 최대 500만원 | 조사·분리·보호 미이행 |
| 사용자가 직접 가해자 | 과태료 최대 1,000만원 | 형사 아님 |
| **보복성 불이익 처우** | **3년 이하 징역 / 3천만원 이하 벌금** | 유일한 형사처벌 조항 |

→ **핵심 구조적 한계**: 괴롭힘 행위 자체는 형사처벌 불가. 보복에만 형사 조항 존재. 피해자 입장에서 '가해자 형사처벌'은 법적으로 불가능한 기대.
