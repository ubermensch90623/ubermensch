## 2. 핵심 발견

### 2-1. 청년 비정규직 비율 15년 추이 (확정 수치)

```
20대 청년 비정규직 비율 (경제활동인구조사 부가조사, 8월 기준)
2010: 31.1%
2020: 37.7%  (+6.6%p / 10년)
2024: 43.1%
2025: 43.9%  ← 현재 수준 (1년 만에 +0.8%p)
```

**구조 해석**: 10년마다 +6~7%p 상승 → 현재 추세대로면 2030년대 초 50% 돌파 예상. 90년생(1990~1999) 코호트는 2010년대 초 노동시장 진입 시기부터 30%대 비정규직 시대를 살았고, 2025년 현재 35세 전후에도 비정규직 비율이 44%에 육박.

### 2-2. 계약직 종료 후 경로 구조 (수치 직접 확인 한계 — 공식 경로 자료)

**KLI 패널브리프 23호 (2023-02) 제목 확인**: "비정규직의 정규직 전환 현황" — 장기 패널 추적 데이터.  
직접 접속 불가로 내부 수치 미확인. 다음 학습 큐로 이월.

**간접 추론 (공식 자료 기반)**:
- 공공부문 정규직 전환 정책(2017~2020): 목표 20.5만명 중 97.4% 완료 — **일회성 종료**
- 이후 공공기관 신규 채용은 계속 기간제·계약직 중심 채용으로 회귀
- 민간 대기업 비정규직도 증가 (고용형태 공시 2024년 3월 데이터 공시됨)

### 2-3. 구조적 함정 메커니즘

```
[계약직 채용]
    ↓ (2년 기간제법 만료)
[1] 정규직 전환  → 소수 경로 (공공기관 전환 정책 이후 점점 희소)
[2] 무기계약직   → 임금 53% 수준 유지, 승진 차단 (5/22 확인)
[3] 재계약       → 2년 리셋 반복 (직무 경험 누적↑, 신분 변화 없음)
[4] 계약종료     → 실업급여 → 구직 → 다시 계약직 진입 가능성 높음
```

**핵심**: [4]→[계약직 채용]으로 순환하는 비율이 높을수록 "장기 비정규직 함정" 형성.  
청년 코호트 단위 패널 분석: KLI 패널브리프 23호가 이 순환 비율을 정량화한 자료 — 직접 수치 미취득 (다음 큐).

### 2-4. 정부 청년정책 기본계획 2026~2030 시사점

- 정부 스스로 "니트·불안정 고용 청년" 구조 공식 인정
- 대상: 16~25세 → **30대 계약직은 정책 사각지대 (25세 초과)**
- 90년생 35세 전후는 청년정책 수혜 범위 밖 → 구조적 지원 없음
