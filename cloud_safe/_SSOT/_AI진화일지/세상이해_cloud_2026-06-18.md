## 종환 방어용 데이터 (실전 활용)

### 면접·협상 레버리지
- **"왜 공기업 지원했나?" 답변 근거**: 비정규직 임금이 정규직의 65.2%에 불과하고 월 격차 180만원(연 2,160만원) — 구조적 불이익 탈출이 합리적 선택임을 수치로 설명 가능
- **국민연금 가입률 격차(31%p)**: 복지 측면 불이익도 실증 — 단순 임금 이상의 구조적 차별

### 직장 내 괴롭힘 대응 근거
- 직장 내 괴롭힘 신고: **1만6000건** 돌파 — 신고 자체가 이례적이지 않음
- 피해자 19.4% 자해·자살 고민 → 심리적 위험 수준 심각, 법적 대응 정당성 높음
- 가해자 상급자 多 + 내부 조사 한계 → 노동청 외부 신고 유효 경로

### 이재명 정부 리스크
- 노동 유연성 언급 = 비정규직 보호 완화 시그널 가능성 → 현 계약직 처우 개선 기대 낮춤, 공채 속도 중요
