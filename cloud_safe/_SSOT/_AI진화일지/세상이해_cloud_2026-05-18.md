## 2. 도메인별 핵심 발견

### 2-1. 계약직 처우 (고용노동부 공식, 2026-01)

- **임금상승률 격차**: 상용근로자 +3.1% vs 임시일용 +0.7% (4.4배).
  → 계약직은 경기 회복기에도 임금 혜택 구조적으로 배제됨.
- **고용량 격차**: 상용 +8만 2,000명 vs 임시일용 +1만 4,000명 증가.
  → 신규 고용 5.9명 중 상용 5명, 임시 1명 비율 — 정규직 쏠림 지속.
- 출처: https://www.korea.kr/briefing/policyBriefingView.do?newsId=156746284

### 2-2. 갑질 (직장갑질119, 2026-03)

- **원청 갑질 55%**: 하청·계약직 위치일수록 구조적 노출 불가피.
- 갑질 유형 순위:
  1. 임금·휴가·복지 차별 **44%**
  2. 하청 위험업무 전가 **37.3%**
  3. 채용·인사 개입 **34.6%**
  4. 직장 내 괴롭힘·성희롱 **25.6%**
- **신고율 15.3%** — 피해자 절반 이상 "참거나 모른 척".
  피해자 중 자해·자살 고민 경험 ~20% (경향신문 2025-07).
- 출처: https://www.koreadaily.com/article/20260314231904286 / https://www.khan.co.kr/article/202507141114001

### 2-3. 90년생 청년 비정규직 — 부분 취합

- KOSIS 비정규직 비율 공식 지표(index.go.kr idxCd=4214) WebFetch 차단 — 수치 직접 미취합.
- 고용형태별근로실태조사 2025-06 기준 결과 공개됨 (stathtml.moel.go.kr) — 후속 세션 직접 접근 필요.
- 90년생(현재 36세, 밀레니얼 후반): 경기 침체기 첫 취업 → 비정규직 진입 세대 중 계층상승 정체층.

## 4. 종환 방어용 데이터 (구체 수치)

- **협상 근거**: "임시일용 임금상승률 0.7% vs 상용 3.1% — 고용노동부 공식 2026-01" → 계약직 임금협상 시 구조적 불리 입증 가능.
- **갑질 대응 근거**: 원청 갑질 55% (직장갑질119 2026-03 n=1,000 공식조사) → 개인 문제 아닌 구조적 현상 — 법적 대응 시 사회적 입증 자료로 활용 가능.
- **침묵 합리성**: 신고율 15.3% — 신고 시 보복 구조가 실질적임을 수치로 방어. 종환이 "참았다"면 84.7%와 같은 합리적 선택.
- **탈출 정당성**: 계약직 임금상승률 0.7% → 30년 근무해도 실질임금 정규직 1/4 수준 증가 → 공시 도전이 유일한 계층이동 경로임을 데이터로 뒷받침.
