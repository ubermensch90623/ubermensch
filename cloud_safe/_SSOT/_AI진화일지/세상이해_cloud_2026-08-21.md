## 4. 합격 답변 4단계 구조 (공기업 특화)

```
[1단계] 공백 이유 — 솔직하되 간결 (30초 이내)
  → "취업 준비에 집중하기 위해 / 직무 전환 준비를 위해 / 건강 관리 후 재도전을 위해"
  → 변명·포장 과잉 금지. 사실 기반 1문장.

[2단계] 기간 중 활동 — 직무 연관성 최소 1개 (1분)
  → 자격증·강의 수강·프로젝트·아르바이트(직무 연관) 중 구체 시기·결과 포함
  → "쉬면서 공부했다" 수준은 B급. "OO 자격증 취득(YYYY-MM), XX 강의 수강 OO시간" 수준이 A급

[3단계] 직무 연결 논리 — 이 기관·이 직무로 연결 (30초)
  → 공백 중 경험 → "그래서 이 기관의 OO 직무에 직접 적용 가능하다"
  → 기관 특정 연결이 없으면 "어디든 지원하는 사람" 인상

[4단계] 현재 준비 완료 선언 — 확신 있는 마무리 (15초)
  → "지금은 OO 상태로 즉시 기여 가능합니다"
  → 미래 시제가 아닌 현재 완료 시제로 마감
```
