## 2. 핵심 발견

### 2-1. 채용형 인턴이 공기업 신입 주류 경로로 고착화

| 지표 | 수치 | 출처·신뢰도 |
|------|------|------------|
| 채용형 인턴 운영 기관 비율 | **80%+** | 잡코리아 집계 / 중간 |
| 채용형 인턴 → 정규직 전환율 | **90%+** | 복수 채용 플랫폼 집계 / 중간 |
| 2026 하반기 공기업 채용 총규모 | 약 **2.8만 명** | 잡코리아 / 중간 |
| 인턴 근무 기간 (평균) | 2~3개월 | 업계 다수 언급 / 낮음 |

**구조 해석**: 순수 '정규직 공채' 비중 축소, 채용형 인턴이 실질 관문. 전환율 90%+는 단기 성과 검증 후 전환하는 구조로, 경쟁은 인턴 선발 단계에서 이미 결정됨.

### 2-2. 정책금융기관 NCS 2026 출제 경향

| 항목 | 변화 방향 | 출처·신뢰도 |

| 문제 유형 | SJT(상황판단형) 강화 | 수험업계 다수 / 낮음 (마케팅 가능성) |
| 출제 중심 | 실제 직무 상황 + 정보 해석 | 링커리어 정리 / 낮음 |
