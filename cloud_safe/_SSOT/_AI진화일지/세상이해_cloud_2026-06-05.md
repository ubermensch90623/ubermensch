## 2. 핵심 발견 (evidence_gate 통과 수치)

### 2-1. 산재 인정 현황 — 급증 구조 (출처 A·B — 한국경제 2025.10.08 WebSearch 요약 수치)

| 지표 | 수치 | 비고 |
|------|------|------|
| 정신질병 산재 승인 | 2015년 46건 → 2024년 **471건** | 9년간 약 10.2배 |
| 적응장애 산재 | 2018년 51건 → 2024년 **250건** | 6년간 약 4.9배 |
| 2024년 정신질병 산재 1위 | 적응장애 **250건** | 전체 471건의 53.1% |
| 2024년 정신질병 산재 2위 | 우울증 **87건** | 전체의 18.5% |
| 2024년 정신질병 산재 3위 | PTSD **68건** | 전체의 14.4% |
| 정신질환 평균 요양기간 | **2년** | 신체 산재 대비 장기 |

**전환점**: 직장내괴롭힘 금지법 2019.07.16 시행 이후 적응장애 산재 급증 → 법 시행이 산재 인식 경로 열어줬으나 **실제 집행·처벌 강도는 2.8%(2022 가해자 처벌율, 5/29 세션 확인)**와 대비됨. 산재 신청이 법적 구제 현실적 대안으로 기능 중.

### 2-2. 심리 후유증 유형 구조 (출처 A + 5/29 세션 교차)

직장내 괴롭힘 관련 산재 인정 3대 정신질환:
1. **적응장애** (2024년 250건 / 전체 53%): 직장이라는 환경 자체에 적응 실패 → 환경 제거(이직·퇴직)가 회복 경로의 핵심
2. **우울에피소드·우울증** (87건 / 18.5%): 만성화 가능성 / 평균 요양 2년 대입 시 치료 비용·이직 공백 장기
3. **PTSD** (68건 / 14.4%): 가장 중증 / 섬광 기억(flashback)·회피 반응 → 동일 유형 직장 재취업 어려움

**공통 패턴**: 피해자 개인의 취약성이 아닌 **환경 자극(괴롭힘 행위)**에 대한 정상 반응. 환경 제거 없이 개인 치료만으로 회복 제한적.

### 2-3. 계약직 피해자 구조적 취약성 (출처 H + 5/29 세션 연계)

- 계약직은 계약 만료를 이용한 **묵시적 보복**(계약 미연장)이 가능 → 신고 후 불이익 증거화 어려움
- 산재 신청 시 계약 만료와 병행하면 **요양급여 수급 기간 중 고용 공백** 발생 (평균 요양 2년 × 계약직 = 재취업 대기 구조)
- 갑질 가해자 처벌율 2.8% + 계약직 계약 미연장 = **사실상 무대응 구조**

### 2-4. 복귀 경로 현황 (출처 F·G + 법령 정보)

한국 근로기준법 제76조의3 피해자 보호조치 (사업주 의무):
- 근무장소 변경 / 배치전환 / 유급휴가 부여 (피해자 요청 시)
- **단**: 계약직은 배치전환 대상 부서 자체가 없는 소규모 사업장이 다수 → 조치 실효성 낮음

고용노동부 협업 프로그램 (2024): 예방 교육 중심, 피해자 심리치료·복직 연계 지원 미흡 (출처 H 방향성)

'안식처' 프로그램 (경향신문 2025.04): 중대재해·갑질 피해자 심리 안정 + 생활 복귀 지원 — 존재 확인, 접근 조건·규모 미확인

## 4. 종환 방어용 구체 데이터

1. **갑질 피해 시 산재 경로 인지**: 적응장애·우울증·PTSD 진단 + 업무 연관성 입증 시 산재 신청 가능. 2024년 산재 승인 471건 (2015년 46건 대비 10배) → **제도 경로 현실화 확인**. 접수: 근로복지공단 (comwel.or.kr 직접 신청 가능).

2. **요양기간 평균 2년 의미**: 산재 승인 후 평균 2년 요양 → 요양급여 (치료비 전액 + 휴업급여 70%) 수급 가능. 계약직은 계약 만료 후라도 **발병 시점 기준**으로 소급 신청 가능 (요양 신청 시효 3년 — 산재보험법).

3. **계약직 갑질 증거 수집 필수 항목**: 이메일·카카오톡·업무 메시지 캡처 (날짜·발신자 포함) + 목격자 진술 + 진료 기록 (진단서에 업무 관련성 명시 필수). 계약 미연장 시 "갑질 신고와 미연장 간 인과관계" 입증이 핵심.

4. **법적 보호조치 요청 루트**: 사내 신고 후 사업주에게 근무장소 변경·유급휴가 서면 요청 → 미이행 시 **과태료 500만원** (근로기준법 제116조). 단 계약직 소규모 사업장은 실효성 낮음 → 고용노동부 진정 병행이 현실적.

5. **이직=회복의 구조적 동치**: 적응장애 회복 핵심이 '유해 환경 제거'. 공기업 합격 후 이직은 **치료적 행위와 동일 방향** — 현재 시험 준비가 심리적 의미에서도 정당화됨.
