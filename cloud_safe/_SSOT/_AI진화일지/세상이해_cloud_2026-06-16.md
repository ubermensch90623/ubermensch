## 2. 역고소 억제 구조 — 3단 레이어

### 2-1. 법적 토대: 신고자 민형사 책임 조항 (Source F)

**규정 원문**: "신고내용으로 명예훼손 또는 무고 등 법적인 문제가 발생할 경우 민형사상의 책임은 신고자에게 있습니다."

**구조적 함의**: 이 조항은 신고 남용 방지용이지만, 가해자 측이 역고소 위협 레버리지로 활용 가능. 계약직 비정규직은 법적 대응 비용 감당 능력 부족 → 위협만으로도 신고 포기 유도.

---

### 2-2. 무고죄 실제 성립 요건 (Source D, E)

| 항목 | 내용 |
|------|------|
| 무고죄 성립 조건 | 피고소인에게 잘못이 없다는 것을 **알면서도** 고의로 허위사실 고소해야 함 |
| 소극적 증명 불가 | "신고사실의 진실성을 인정할 수 없다"는 소극적 증명만으로 무고죄 성립 불인정 |
| 실질적 의미 | 무고죄 인정 기준이 높음 → 가해자가 피해자를 실제 무고로 처벌받게 하기 어려움 |
| 역설 | BUT 가해자는 '무고 위협' 자체로 피해자를 심리적 압박 가능 — 실제 성립 여부와 무관하게 위협 기제 작동 |

> **Evidence gate**: 무고죄 법리 = 대법원 판례 확립 원칙 (검색 스니펫 법률 안내서 복수 일치). 통과.

---

### 2-3. 역고소 위협이 직장내 괴롭힘으로 역인정되는 판례 (Source D, E)

**판례 요지** (worklaw.co.kr·율촌 요약): "신고하겠다고 한 부하직원을 명예훼손 고소하겠다고 위협하면서 정신적 고통을 준 행위 → 직장 내 괴롭힘 인정"

| 구분 | 내용 |
|------|------|
| 가해자 전략 | 피해자 신고 → 맞신고(명예훼손·업무방해) + 손해배상 청구로 강경대응 |
| 법원 판단 | 강경대응 자체가 직장 내 괴롭힘 추가 인정 위험 → 가해자에게도 부메랑 |
| 현실 억제 효과 | 가해자의 법적 위험에도 불구, 계약직·하위 직급 피해자는 소송 자체를 감당할 수 없어 신고 포기 → 가해자 실질 손해 없음 |

---

### 2-4. 2026.4 고용노동부 처리지침 개정 (Source G — Tier 3, 구조 참고용)

**개정 핵심**: 사업주가 가해자인 사건의 처리 구조 명확화. 기존 내부 처리의 이해충돌 문제(사업주 = 가해자이면서 조사자) 해소 시도.

> 수치 없음. Tier 3이므로 구조 설명 참고용만. 직접 조항 확인 필요 (다음 큐).
