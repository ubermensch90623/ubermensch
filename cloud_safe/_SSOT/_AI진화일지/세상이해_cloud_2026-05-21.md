## 2. 핵심 발견

### 2-1. 직장 내 괴롭힘 신고 건수 추이 (고용노동부 공식)

- **7,774건(2021) → 8,961건(2022) → 10,028건(2023)** — 매년 약 1,000건 이상 증가
- 2023년 처음으로 연간 1만 건 돌파
- 신고 건수 증가 ≠ 실제 피해 증가. 법 인식 제고로 신고 문턱 낮아진 효과 포함
- **구조적 갭**: 경험률 34.5%(약 800만 명 추정) vs 연간 신고 1만 건 → 신고율 극히 저조

### 2-2. 근로기준법 76조 법적 구제 절차 구조

```
피해 발생
  ↓
① 내부 신고 (누구든지 — 당사자·목격자 모두 가능, 근로기준법 76조의3)
  ↓
② 사용자: 지체없이 객관적 조사 실시 의무 (위반 시 과태료)
  ↓
③ 조사 중: 피해자 요청 시 근무장소 변경·유급 휴가 가능
  ↓
④ 괴롭힘 확인 → 가해자 징계·근무 분리 조치 의무
  ↓
⑤ 피해자에 불이익 처우 시 → 3년 이하 징역 / 3,000만원 이하 벌금 (형사처벌)
```

**계약직 구조적 취약점**:
- 사용자 = 조사 주체 → 사내 신고는 제도적 이해충돌
- 계약 갱신권 = 사실상 불이익 처우 도구 (계약 미갱신 = 합법적 형사처벌 회피)
- **대안 경로**: 노동청 직접 진정(→ 공식 조사 권한) / epeople.go.kr 갑질신고센터 / 갑질119 카카오채널(pf.kakao.com/_uRaRG)

### 2-3. 사용자가 가해자인 경우 (공공기관 계약직 현실)

- 내부 신고 채널 → 무의미 (사용자 자신이 가해자)
- 고용노동부 노동청 진정이 1차 공식 경로
- 단, 진정 접수 후 처리까지 평균 수개월 → 계약 갱신 시점과 충돌 위험
- **실무 전략**: 증거 누적(날짜·내용·목격자) → 계약 갱신 직후 진정 타이밍 또는 퇴사 후 진정

### 2-4. 비정규직 비율 최신 재검증 (2025-10 기준)

| 집계 기관 | 비율 | 기준 |
|-----------|------|------|
| 국가데이터처 | **38.2%** | 2025-10 경제활동인구 부가조사 협의 정의 |
| 한국비정규노동센터 | **41.0%** | 간접고용·특수고용 포함 확장 정의 |
| 김유선(한국노동사회연구소) | **41.5%** | 최광의 정의 |

- 5/20 파일의 65.2%는 **고용형태별근로실태조사(2025-06)** 기준 시간당임금 비율
- 오늘 68.9%/66.8%는 **경제활동인구 부가조사(2025-10)** 기준 — 조사 방법론 차이 (임금총액 vs 시간당 환산 차이 존재)
- **두 수치 모두 유효하나 출처 구분 필수**

### 2-5. 2026 임금격차 전망

- 2026 최저임금 인상률 2.9% — 경제성장률·물가상승률 2% 안팎과 유사 → 실질 임금 정체
- 비정규직 임금격차 확대 재연 가능성 (KLI 고용노동브리프 114호 2025-02 전망, PDF 직접 접근 미완)
- 공공부문 무기계약직 차등인상 +0.5%p (5/20 운영매뉴얼 기록) — 정규직 격차 좁히기 제한적
