## 2. 핵심 발견 — 직장내괴롭힘법 집행 실효성 구조

### 2-1. 신고 비율 15% — 암수 범죄 구조

| 피해 대응 | 비율 |
|-----------|------|
| 그냥 참음 | ~50% |
| 직장 내 자체 해결 시도 | ~25% |
| **외부 신고 (고용노동부·직장갑질119 등)** | **15.3%** |
| 기타 | 나머지 |

- 출처: 경향신문(A) / 직장갑질119 조사 인용
- **함의**: 실제 피해 건수 대비 제도 접수 건수 = 1/7 수준. 나머지 6/7은 암수(暗數).
- 신고 저해 요인: 계약 미연장 보복 (비정규직), 가해자가 사업주인 경우 조사 실효성 불신, 비밀유지 위반 우려

### 2-2. 비정규직·계약직에서 신고율 더 낮은 구조 (추정)

직장갑질119 5주년 자료집(B) + 공공기관 갑질 피해 65% 비정규직 집중(5/20 자료 연계):

```
계약직 신고 저해 메커니즘:
  갑질 피해 발생
    → 신고 시 계약 미연장 보복 위협
    → 계약 기간 중 신고 = 사실상 자발적 퇴직과 동일 결과 위험
    → 신고율 전체 15% 대비 계약직은 더 낮을 것 (수치 미확인)
    → 법의 사각지대 = 보호가 필요한 집단에서 가장 낮은 접근성
```

### 2-3. 과태료 500만원 — 억제력 부재

| 위반 행위 | 법정 제재 |
|-----------|-----------|
| 조사 의무 위반 | **500만원 이하 과태료** |
| 피해자 불이익 조치 | **3년 이하 징역 OR 3천만원 이하 벌금** (형사) |
| 비밀유지 의무 위반 | **500만원 이하 과태료** |
| 사업주 행위자 확인 시 | 즉시 과태료 (시정지시 절차 없이) |

- 출처: 국가법령정보센터(E)
- **문제**: 500만원 = 중소기업 월 매출의 극히 일부. 억제 효과 미미.
- 형사(3천만원 벌금) 적용은 '피해자 불이익 조치' 시만 — 괴롭힘 행위 자체는 형사 아님.

### 2-4. 2026년 4월 제도 개정 — 의미와 한계

**변경 내용** (D, lawtimes.co.kr):
- 기존: 사업장 자체 조사 → 결과 보고 → 고용노동부 검토
- 개정: 행위자가 **사업주·경영담당자**인 경우 → 근로감독관 **직접 조사** 의무화

**의미**: 사업주가 행위자일 때 자체 조사의 이해충돌 문제(= 가해자가 조사 지휘) 구조적 해결 시도.

**한계**:
- 여전히 '사업주·경영담당자'로 한정 — 중간 관리자 갑질은 여전히 사업장 자체 조사 구조
- 근로감독관 인력 부족 → 직접 조사 실제 처리속도 불확실
- 비정규직의 경우 계약 만료 후 신고 = 이미 피해 누적 상태에서 구제 지연

### 2-5. 법 시행 6년 구조적 진단

```
2019년 직장내괴롭힘법 시행 
  → 신고 채널 생겼으나 억제 구조는 해결 안 됨
  → 피해자 보호 의무 있으나 실행 기제 약함
  → 가장 취약한 집단(계약직·비정규직)에서 접근성 최하
  → 2026년 4월 개정이 부분 개선이나 근본 구조 유지
```
