## 5. 구조 해석 — "36세 공기업 신입" 실질 장벽 지도

```
법적 장벽: 없음 (연령 차별 금지, 블라인드 채용)
          ↓
서류 단계: 나이 미기재 → 실질 필터 없음
          ↓
필기 단계: NCS·전공 점수로만 평가 → 나이 무관
          ↓
면접 단계: 심리적 장벽 작동
          - 면접관이 "왜 지금?" 묵시적 판단
          - 공백기·계약직 이력 서사화 필수
          - 경력 있는 36세 > 경력 공백 32세 (현직 증언)
          ↓
합격 후 조직 적응: 상사·선배 나이 역전 가능
          → 공기업 연공 문화 + 블라인드 = 현실 마찰 존재
```

**핵심 구조**: 법 = 장벽 없음 / 필기 = 장벽 없음 / 면접 = 서사로 돌파 / 조직 = 준비 필요.
