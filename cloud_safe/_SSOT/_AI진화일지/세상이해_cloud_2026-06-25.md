## 구조 분석

### 1. 세대 역전의 수치적 확인

```
2026년 3월 취업자 전체 순증: +23만4,000명
  ├─ 60세 이상:  +28만7,000명 (전체 증가분 초과)
  ├─ 30~40대:   소폭 증가
  └─ 청년(15~29세): -14만7,000명  ← 적자
```

→ 고용률 상승의 실체는 **고령층 고용** / 청년은 역성장.

### 2. 확장실업률 갭 — 17.4% vs 7.6%

공식 실업률 7.6%는 구직 활동 기준. 구직 포기·비경제활동 상태 포함 시 17.4%.  
갭 **9.8%p**는 "구직 단념 + 쉬었음" 청년 규모가 공식 실업자 규모와 맞먹음을 시사.

### 3. 25~29세 취업자 9년 만에 최저

- 2026년 2월: **234만6,000명** (2017년 224만5,000명 이후 최저치 방향 추락)  
- 감소 업종: **숙박·음식점업, 정보통신업, 제조업** (AI 자동화 + 경기 냉각 복합)

### 4. '쉬었음' 청년 — 자발적 이탈 vs 구조적 배제

BOK 이슈노트 제2026-3호: 미취업 청년 중 **재진입 의향 없는 군이 증가**. 이는 단순 경기 순환 문제가 아니라 노동시장에 대한 신뢰 상실로 해석.

### 5. 이중 압박 (BOK 제2026-2호)

노동시장 진입 지연 → 자산 형성 지연 → 주거비 부담 악화 → 결혼·출산 포기 → 인구 감소 가속. 단일 충격이 아닌 **생애 경로 전체를 압박하는 복합 구조**.
